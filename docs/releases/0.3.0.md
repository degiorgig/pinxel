Pinxel 0.3.0 is the first release signed with Developer ID and notarized by Apple.

## What's new

- The app opens normally on any Mac: no more right-click ▸ Open on first launch.
- The `.dmg` and the app inside the `.zip` carry the notarization ticket, so the check also works offline.
- Releases are now built, signed and published automatically from the repository, with SHA-256 checksums in the notes.

## Updating from 0.1.0 or 0.2.0

The app is signed with a new certificate, so macOS asks for the Screen Recording permission again. If capture stays blank, remove Pinxel from System Settings ▸ Privacy & Security ▸ Screen Recording, add it again and relaunch the app.

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.
