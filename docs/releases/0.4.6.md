Pinxel 0.4.6 makes PDF export safer and sharper, and fixes a few rough edges.

## Changes

- PDF export: text covered by other opaque text (for example a row of █ typed over a password) is no longer left in the file.
- PDF export: arrows, lines, shapes, text, callouts, steps and pen strokes on top of a capture stay sharp vectors when you zoom in, and text stays selectable. What they cover is still removed from the file.
- Automatic saving: captures saved at the same moment no longer overwrite each other; each one gets its own file.
- An incomplete scrolling capture stays out of the library: clicking a thumbnail in its window opens that capture in a new window instead of saving the incomplete one.
- Quick previews: when the stack starts over, it is moved slightly, so the oldest previews stay visible.

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
