Pinxel 0.3.1 fixes two small issues.

## Fixes

- New from Clipboard and Edit Last Capture in the menu bar now bring the editor to the front, as New already did. The window used to open behind the other apps. Captures opened from the library come to the front too.
- About Pinxel and the Finder info show the copyright as "© 2026 Giovanni Degiorgi".

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
