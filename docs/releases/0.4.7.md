Pinxel 0.4.7 makes deleting captures from the library strip easier and safer.

## Changes

- Library strip: the delete button (X) now appears as soon as the pointer is anywhere over a thumbnail, including the empty space beside a tall capture, and it is easier to click.
- Library strip: on a short strip the delete button gets smaller, so most of the thumbnail still selects and opens the capture.
- Keyboard navigation can no longer reach the hidden delete button.

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
