Pinxel 0.2.0 speaks four languages.

## What's new

**Languages**
- The interface is available in English, Italian, German and French, and follows the language of your Mac (or the per-app language in System Settings ▸ General ▸ Language & Region ▸ Applications). Any other language falls back to English.
- Everything is translated: menus, toolbar, settings, panels, alerts, notifications, Undo/Redo names, the right-click menu, tooltips, accessibility labels and the document types shown in the Finder.
- The default file name follows the language (`Pinxel 2026-10-20 at 08.40.00`, `… alle …`, `… um …`, `… à …`). A custom file-name template is kept as it is.
- German and French translations have not yet been reviewed by a native speaker; corrections are welcome.

**Library**
- The library now lives in `~/Pictures/Pinxel/Library`, with the same name in every language.
- The old `~/Pictures/Pinxel/Libreria` folder from 0.1.0 is not moved or read. To bring old captures over, drag them onto the library strip.
- A damaged library index is now kept aside as `library.json.corrupt`.

**Other changes**
- ⌥⌘V is now called "Paste as Image".

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

This build is signed with a development certificate and is not notarized. It opens normally on the Mac of whoever built it. Elsewhere macOS blocks it: open it with right-click ▸ Open.
