Pinxel 0.4.1 changes where the Mac App Store version keeps its files.

## Changes

- Mac App Store version: Pinxel no longer asks for access to the Pictures folder. The library lives inside the app's container, and automatic saving asks you to choose a folder the first time you turn it on.
- The version from GitHub is unchanged: the library stays in `~/Pictures/Pinxel/Library`.

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
