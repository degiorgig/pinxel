Pinxel 0.4.3 keeps your captures in one editor window.

## Changes

- A new capture that opens the editor now appears in the editor window already open, instead of a new window. The capture that was there is saved first, as when you click a thumbnail in the library.
- If that window holds an untitled document with something in it, the capture opens in a new window, so nothing is lost. With no editor window open, a new one opens as before.

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
