Pinxel 0.4.0 can open at login and no longer needs the Accessibility permission.

## New

- **Open at login.** Settings ▸ General ▸ Open Pinxel at login starts Pinxel in the menu bar every time you log in. On first launch Pinxel asks once whether to turn it on; it stays off until you say yes. Changes made in System Settings ▸ General ▸ Login Items show up in Pinxel too.

## Changes

- Scrolling capture: Esc cancels and Return finishes without the Accessibility permission. Pinxel no longer asks for it.
- The automatic saving folder chosen in Settings keeps working if you rename or move it.
- After you grant the Screen Recording permission, Pinxel relaunches itself reliably, with the global shortcuts working right away.
- Pinxel is now licensed under the PolyForm Strict License 1.0.0: free for personal and other noncommercial use. Commercial use needs a separate license, see [COMMERCIAL.md](https://github.com/degiorgig/pinxel/blob/main/COMMERCIAL.md).

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
