Pinxel 0.4.5 makes exporting quicker and keeps your editor window open when you delete a capture.

## Changes

- The share button in the editor toolbar is now an Export menu: Share, as before, or Export as PNG, JPEG, HEIC or PDF, which opens the Export panel with that format already chosen.
- Deleting the capture shown in an editor window (from the strip's context menu, with ⌫ or with the X on its thumbnail) no longer closes the window: it shows the next capture in the strip instead. The window closes only when no capture is left.
- The handle for dragging the image out of the canvas has a clearer icon.

## Install

Open the `.dmg` and drag Pinxel into Applications, or unzip the `.zip`. On first launch, grant the Screen Recording permission.

The app is signed with Developer ID and notarized by Apple, so it opens normally on any Mac.
