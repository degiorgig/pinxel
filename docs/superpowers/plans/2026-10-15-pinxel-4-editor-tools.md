# Pinxel 4 — Editor Tools Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the v1 editor: text and callouts edited on the canvas, magnifier, crop, cut-out, the Image menu (resize, border, shadow, padding), magnetic guides, quick styles, pasting images, drag-out of the image, read-only and recovery UX, menus that enable and name their actions, plus the minors deferred by plans 2 and 3.

**Architecture:** Everything testable stays in PinxelKit. `EditorUI` grows the new tools inside `ToolController` (text/callout requests, magnifier parts, crop state, cut band, snapping), pure helpers (`RichTextBridge`, `TextEditing`, `MagnifierPlacement`, `CropGeometry`, `CutGeometry`, `SmartGuides`, `ResizeDraft`, `CanvasStyleEditing`, `ImagePlacement`, `EditorMenuState`), an `AssetStore` for pasted images, a `QuickStyleStore`, and `CanvasTextEditor` (the temporary `NSTextView` over a text object). `AppCore` gets `TemporaryFiles` and `DocumentRecovery`. The app adds inspector sections, the Image menu with two sheets, `EditorFocus` (the main editor's menu state), the drag-out toolbar item and the recovery attempter.

**Tech Stack:** Swift 6, macOS 15+, Xcode 27, XcodeGen 2.46, AppKit (`NSView`, `NSTextView` TextKit 1, `NSDocument`, error recovery), SwiftUI (`.inspector`, `.sheet`, `Commands` with `@ObservedObject`, `TextFormattingCommands`, `.draggable` + `FileRepresentation`), Observation, Core Graphics, Swift Testing (package), XCTest/XCUITest (app).

**Spec:** `docs/superpowers/specs/2026-10-14-pinxel-capture-editor-design.md` (sections 5.3, 6.1–6.4, 9, 10). Builds on plans 1–3 (`docs/superpowers/plans/2026-10-14-pinxel-{1-core,2-app-capture,3-editor-core}.md`).

**Branching:** plan 3 is PR #3 (`feat/pinxel-editor-core`), not yet merged. Branch this plan from it: `git checkout feat/pinxel-editor-core && git checkout -b feat/pinxel-editor-tools`. When PR #3 merges, rebase onto `main` (`git rebase main`) before opening this plan's PR.

**Rulings at plan time** (each with its cost if wrong):

- Callouts have no rotation handle; their eight handles sit on the bubble, a ninth on the tail tip. Cost: a rotated callout needs a manual file edit.
- The text overlay is not rotated: a rotated text is edited upright and drawn rotated again on commit. Cost: brief visual jump on rotated texts.
- Bold, italic and underline from the inspector apply to the whole text; per-word styling uses `⌘B`/`⌘I`/`⌘U` (Format menu) while typing. Cost: none, both paths exist.
- Magnetic guides apply to moving objects (spec §6.3 "durante il trascinamento"), not to resize or creation. Cost: polish request later.
- Quick styles record the style of every object created with a tool (the "last 8 used"); applying one changes the selection or the tool. Cost: none.
- Drag-out (spec §9): the toolbar item drags a PNG. The window's proxy icon keeps the standard macOS behaviour (it drags the `.pinxel` file of a saved document; untitled documents have no proxy icon). Familiar behaviour wins over the spec's literal reading. Cost: users who want a PNG use the toolbar item.
- Recovery opens the intact background at the main screen's scale, because a damaged `document.json` no longer says the original scale. Cost: a 1x capture recovered on a Retina Mac opens at half size; Image → Resize fixes it.
- Plan-2 minors included: overlay arrows move 1 px, tolerant settings decoding with sanitized shortcuts, atomic auto-save, unique temporary file names. Left for later (with reason): per-display size label and full redraw in the overlay (cosmetic), cursor push/pop (no visible bug), permission revoked mid-session (needs a real revoke to test), window scale from snapshot (multi-display edge case). Cost: those stay as known minors.

## Global Constraints

- Platform floor `macOS 15`; Swift 6 language mode in package and app; strict concurrency, no warnings.
- No third-party dependencies. `Pinxel.xcodeproj` is generated by XcodeGen and git-ignored; after adding or removing app files run `xcodegen generate`.
- `EditorUI` depends only on `DocumentModel` and `Rendering` (spec §4). `Persistence` stays out of it.
- All drawing of the document goes through `DocumentRenderer.render` (spec §9). Overlays (handles, crop, cut band, guides, text frame) are drawn by the canvas on top.
- Document coordinates: pixels of the image after image operations, origin top-left, y down. Canvas = document + `canvasStyle.padding`. View: points, flipped. `pointsPerPixel = zoom / document.scale`.
- One continuous interaction = one command on mouse-up; one text editing session = one command at the end (spec §5.4, §6.3).
- Image operations transform annotations inside the same command (spec §5.3, already true of `ApplyImageOperation`); undo is exact.
- Locked annotations are never modified; read-only documents accept no edits through any path (tools, text, crop, cut, paste, Image menu, inspector).
- Tool shortcuts (single key, no modifiers): V A L R T C S P H B M K X (spec §6.2).
- Pasted images are stored as `assets/<uuid>.png` in the archive (spec §3, §8).
- User-visible strings are Italian. Logging subsystem `com.degiorgi.pinxel`.
- Apple design (from the `apple-design` skill, applied to AppKit): feedback on mouse-down, 1:1 tracking that keeps the grab offset, native controls and system colors in light and dark, SF Symbols with help tags that name the shortcut, menus that disable what cannot be done and name what Undo will undo, no animation that blocks input, familiar platform behaviour over novelty.

```swift
import AppKit
import DocumentModel

/// Conversione fra `RichText` del modello e `NSAttributedString` per l'`NSTextView` di modifica sulla tela.
/// Le dimensioni sono in pixel del documento, come in `Rendering`.
public enum RichTextBridge {
    public static func font(family: String, size: Double, bold: Bool, italic: Bool) -> NSFont {
        let base = NSFont(name: family, size: size) ?? .systemFont(ofSize: size)
        var traits = base.fontDescriptor.symbolicTraits
        if bold { traits.insert(.bold) }
        if italic { traits.insert(.italic) }
        guard traits != base.fontDescriptor.symbolicTraits else { return base }
        return NSFont(descriptor: base.fontDescriptor.withSymbolicTraits(traits), size: size) ?? base
    }

    /// Attributi di un run; senza run, quelli del testo digitato in un campo vuoto.
    public static func attributes(_ text: RichText, run: TextRun? = nil) -> [NSAttributedString.Key: Any] {
        var attributes: [NSAttributedString.Key: Any] = [
            .font: font(family: text.fontFamily, size: text.fontSize, bold: run?.bold ?? false, italic: run?.italic ?? false),
            .foregroundColor: (run?.color ?? text.color).nsColor,
            .paragraphStyle: paragraphStyle(text.alignment),
        ]
        if run?.underline == true { attributes[.underlineStyle] = NSUnderlineStyle.single.rawValue }
        return attributes
    }

    public static func attributedString(_ text: RichText) -> NSAttributedString {
        let result = NSMutableAttributedString()
        for run in text.runs where !run.text.isEmpty {
            result.append(NSAttributedString(string: run.text, attributes: attributes(text, run: run)))
        }
        return result
    }

    /// `template` dà famiglia, dimensione, colore e allineamento; grassetto, corsivo, sottolineato e colore
    /// dei run vengono dagli attributi. Run adiacenti uguali vengono uniti.
    public static func richText(from string: NSAttributedString, template: RichText) -> RichText {
        var runs: [TextRun] = []
        let content = string.string as NSString
        string.enumerateAttributes(in: NSRange(location: 0, length: string.length)) { attributes, range, _ in
            let traits = (attributes[.font] as? NSFont)?.fontDescriptor.symbolicTraits ?? []
            let underline = ((attributes[.underlineStyle] as? Int) ?? 0) != 0
            var color = (attributes[.foregroundColor] as? NSColor).map(RGBA.init(nsColor:))
            if let value = color, value.isClose(to: template.color) { color = nil }
            let run = TextRun(text: content.substring(with: range), bold: traits.contains(.bold), italic: traits.contains(.italic),
                              underline: underline, color: color)
            if let last = runs.last, last.bold == run.bold, last.italic == run.italic,
               last.underline == run.underline, last.color == run.color {
                runs[runs.count - 1].text += run.text
            } else {
                runs.append(run)
            }
        }
        var result = template
        result.runs = runs
        return result
    }

    static func paragraphStyle(_ alignment: RichTextAlignment) -> NSParagraphStyle {
        let style = NSMutableParagraphStyle()
        switch alignment {
        case .left: style.alignment = .left
        case .center: style.alignment = .center
        case .right: style.alignment = .right
        }
        return style
    }
}

extension RGBA {
    /// Uguale entro mezzo passo di un canale a 8 bit (le conversioni di colore arrotondano).
    func isClose(to other: RGBA) -> Bool {
        let tolerance = 0.5 / 255
        return abs(red - other.red) <= tolerance && abs(green - other.green) <= tolerance
            && abs(blue - other.blue) <= tolerance && abs(alpha - other.alpha) <= tolerance
    }
}
```

`PinxelKit/Sources/EditorUI/TextAnnotation.swift`:

```swift
import CoreGraphics
import DocumentModel

extension RichText {
    public var isBold: Bool { !runs.isEmpty && runs.allSatisfy(\.bold) }
    public var isItalic: Bool { !runs.isEmpty && runs.allSatisfy(\.italic) }
    public var isUnderlined: Bool { !runs.isEmpty && runs.allSatisfy(\.underline) }

    public mutating func setBold(_ on: Bool) {
        for index in runs.indices { runs[index].bold = on }
    }

    public mutating func setItalic(_ on: Bool) {
        for index in runs.indices { runs[index].italic = on }
    }

    public mutating func setUnderline(_ on: Bool) {
        for index in runs.indices { runs[index].underline = on }
    }

    /// Colore di tutto il testo: i colori dei singoli run vengono tolti.
    public mutating func setColor(_ color: RGBA) {
        self.color = color
        for index in runs.indices { runs[index].color = nil }
    }
}

extension Annotation {
    /// Testo di un testo o di un callout; `nil` per gli altri tipi (e assegnarlo non fa nulla).
    public var richText: RichText? {
        get {
            switch kind {
            case .text(let data): return data.text
            case .callout(let data): return data.text
            default: return nil
            }
        }
        set {
            guard let newValue else { return }
            switch kind {
            case .text(var data):
                data.text = newValue
                kind = .text(data)
            case .callout(var data):
                data.text = newValue
                kind = .callout(data)
            default:
                break
            }
        }
    }

    public var textRect: CGRect? {
        switch kind {
        case .text(let data): return data.rect.standardized
        case .callout(let data): return data.rect.standardized
        default: return nil
        }
    }

    /// Margine fra il riquadro e il testo, uguale a quello usato da `TextRenderer`.
    public var textInset: Double {
        if case .callout = kind { return 10 }
        return 4
    }

    /// Alza il riquadro del testo fino a `height`; non lo abbassa mai.
    public mutating func growTextHeight(to height: Double) {
        switch kind {
        case .text(var data):
            data.rect = data.rect.standardized
            data.rect.size.height = max(data.rect.height, height)
            kind = .text(data)
        case .callout(var data):
            data.rect = data.rect.standardized
            data.rect.size.height = max(data.rect.height, height)
            kind = .callout(data)
        default:
            break
        }
    }
}
```

```swift
import DocumentModel
import Foundation

/// Fine di una modifica di testo sulla tela: un solo comando per tutta la sessione (spec §6.3).
public enum TextEditing {
    /// Annotazione da disegnare sotto l'`NSTextView`: senza testo (lo mostra la vista), con lo stile
    /// attuale del documento e l'altezza raggiunta dal testo digitato.
    public static func placeholder(for request: TextEditRequest, current: Annotation?, height: Double) -> Annotation {
        var annotation = request.isNew ? request.annotation : (current ?? request.annotation)
        if var text = annotation.richText {
            text.runs = []
            annotation.richText = text
        }
        annotation.growTextHeight(to: height)
        return annotation
    }

    /// Nuovo testo non vuoto → aggiunta; testo esistente svuotato → eliminazione; modificato → aggiornamento
    /// della versione attuale nel documento. `nil` se non cambia nulla o l'oggetto è bloccato o sparito.
    public static func commit(_ request: TextEditRequest, text: RichText, minimumHeight: Double,
                              document: PinxelDocument) -> (any EditCommand)? {
        let isEmpty = text.plainText.trimmingCharacters(in: .whitespacesAndNewlines).isEmpty
        if request.isNew {
            guard !isEmpty else { return nil }
            var annotation = request.annotation
            annotation.richText = text
            annotation.growTextHeight(to: minimumHeight)
            if case .callout = annotation.kind { return AddAnnotations([annotation], name: "Aggiungi callout") }
            return AddAnnotations([annotation], name: "Aggiungi testo")
        }
        guard let current = document.annotations.first(where: { $0.id == request.annotation.id }), !current.isLocked else {
            return nil
        }
        if isEmpty { return DeleteAnnotations(ids: [current.id], in: document, name: "Elimina testo") }
        var updated = current
        updated.richText = text
        updated.growTextHeight(to: minimumHeight)
        guard updated != current else { return nil }
        return UpdateAnnotations(name: "Modifica testo", before: [current], after: [updated])
    }
}

/// Ciò che il pannello proprietà può chiedere al testo in modifica.
@MainActor
public protocol TextEditingControl: AnyObject {
    /// Applica una modifica a tutto il testo (dimensione, colore, allineamento, grassetto…).
    func applyToAll(_ change: (inout RichText) -> Void)
}
```

```swift
import AppKit
import DocumentModel

/// `NSTextView` temporaneo sopra un testo o un callout (spec §6.3). Lavora in pixel del documento:
/// il contenitore ha i bounds del riquadro e la tela gli dà la cornice in punti, così lo zoom scala il testo
/// come lo scala il renderer.
@MainActor
final class CanvasTextEditor: NSObject, NSTextViewDelegate, TextEditingControl {
    let request: TextEditRequest
    let container = FlippedView()
    let textView = NSTextView(usingTextLayoutManager: false)
    /// Riquadro del testo nel documento; l'altezza cresce con il contenuto, non cala.
    private(set) var frame: CGRect
    /// Famiglia, dimensione, colore e allineamento (senza run).
    private var template: RichText
    private let inset: Double
    /// Le annullate della digitazione restano qui: alla fine conta un solo comando nel documento.
    private let typingUndo = UndoManager()
    private var finished = false

    var onChange: ((RichText) -> Void)?
    var onFrameChange: (() -> Void)?
    var onFinish: ((RichText, Double) -> Void)?

    init(request: TextEditRequest) {
        self.request = request
        let annotation = request.annotation
        frame = annotation.textRect ?? .zero
        let text = annotation.richText ?? RichText(runs: [])
        template = text
        template.runs = []
        inset = annotation.textInset
        super.init()
        textView.frame = CGRect(origin: .zero, size: frame.size).insetBy(dx: inset, dy: inset)
        textView.isRichText = true
        textView.allowsUndo = true
        textView.drawsBackground = false
        textView.textContainerInset = .zero
        textView.textContainer?.lineFragmentPadding = 0
        textView.textContainer?.widthTracksTextView = true
        textView.isVerticallyResizable = false
        textView.isHorizontallyResizable = false
        textView.focusRingType = .none
        textView.setAccessibilityIdentifier("pinxel.editor.text")
        textView.textStorage?.setAttributedString(RichTextBridge.attributedString(text))
        textView.typingAttributes = RichTextBridge.attributes(template)
        textView.setSelectedRange(NSRange(location: (textView.string as NSString).length, length: 0))
        textView.delegate = self
        container.addSubview(textView)
        updateHeight()
    }

    var richText: RichText {
        RichTextBridge.richText(from: textView.attributedString(), template: template)
    }

    /// Mette il contenitore sulla tela; `convert` porta un rettangolo del documento in punti della vista.
    func place(in convert: (CGRect) -> CGRect) {
        container.frame = convert(frame)
        container.bounds = CGRect(origin: .zero, size: frame.size)
        textView.frame = container.bounds.insetBy(dx: inset, dy: inset)
    }

    /// Chiude la modifica una volta sola (Esc, clic fuori, cambio di strumento, perdita del fuoco).
    func finish() {
        guard !finished else { return }
        finished = true
        onFinish?(richText, frame.height)
    }

    func applyToAll(_ change: (inout RichText) -> Void) {
        var text = richText
        change(&text)
        let selection = textView.selectedRange()
        template = text
        template.runs = []
        textView.textStorage?.setAttributedString(RichTextBridge.attributedString(text))
        textView.typingAttributes = RichTextBridge.attributes(template)
        let length = (textView.string as NSString).length
        let location = min(selection.location, length)
        textView.setSelectedRange(NSRange(location: location, length: min(selection.length, length - location)))
        contentChanged()
    }

    // MARK: NSTextViewDelegate

    func textDidChange(_ notification: Notification) {
        contentChanged()
    }

    func textDidEndEditing(_ notification: Notification) {
        finish()
    }

    func textView(_ textView: NSTextView, doCommandBy commandSelector: Selector) -> Bool {
        // Esc conferma il testo, come uscire dalla modifica in Keynote.
        if commandSelector == #selector(NSResponder.cancelOperation(_:)) || commandSelector == #selector(NSTextView.complete(_:)) {
            finish()
            return true
        }
        return false
    }

    func undoManager(for view: NSTextView) -> UndoManager? {
        typingUndo
    }

    private func contentChanged() {
        updateHeight()
        onChange?(richText)
    }

    private func updateHeight() {
        guard let layoutManager = textView.layoutManager, let textContainer = textView.textContainer else { return }
        layoutManager.ensureLayout(for: textContainer)
        let needed = (layoutManager.usedRect(for: textContainer).height + 2 * inset).rounded(.up)
```

```swift
import CoreGraphics

public enum MagnifierPlacement {
    /// Riquadro dell'ingrandimento di una lente nuova: la sorgente scalata di `zoom`, a destra della sorgente
    /// (a sinistra se non ci sta), centrata in verticale e dentro l'immagine finché possibile.
    public static func target(for source: CGRect, zoom: Double, imageSize: CGSize, gap: Double = 24) -> CGRect {
        let s = source.standardized
        let size = CGSize(width: s.width * zoom, height: s.height * zoom)
        var x = s.maxX + gap
        if x + size.width > imageSize.width { x = s.minX - gap - size.width }
        if x < 0 { x = max(0, min(imageSize.width - size.width, s.midX - size.width / 2)) }
        let y = max(0, min(s.midY - size.height / 2, imageSize.height - size.height))
        return CGRect(origin: CGPoint(x: x, y: y), size: size)
    }
}
```

```swift
import CoreGraphics
import DocumentModel

/// Riquadro del ritaglio mentre lo si disegna, sposta o ridimensiona. Coordinate del documento.
public enum CropGeometry {
    public enum DragMode: Equatable, Sendable {
        case new, move, resize(Handle)
    }

    /// Riquadro dopo aver trascinato da `start` a `point`; resta sempre dentro `image`.
    public static func dragged(_ mode: DragMode, from start: CGPoint, to point: CGPoint, original: CGRect,
                               image: CGRect, keepAspect: Bool) -> CGRect {
        switch mode {
        case .new:
            let anchor = clamp(start, to: image)
            var corner = clamp(point, to: image)
            if keepAspect { corner = clamp(AnnotationGeometry.squared(from: anchor, to: corner), to: image) }
            return CGRect.bounding([anchor, corner])
        case .move:
            var rect = original.offsetBy(dx: point.x - start.x, dy: point.y - start.y)
            rect.origin.x = min(max(rect.minX, image.minX), image.maxX - rect.width)
            rect.origin.y = min(max(rect.minY, image.minY), image.maxY - rect.height)
            return rect
        case .resize(let handle):
            // La maniglia segue il puntatore mantenendo la distanza da dove è stata presa.
            let handlePoint = HitTesting.boxPoint(handle, of: original)
            let dragged = clamp(CGPoint(x: handlePoint.x + point.x - start.x, y: handlePoint.y + point.y - start.y), to: image)
            let rect = AnnotationGeometry.frame(anchor: HitTesting.boxPoint(handle.opposite, of: original), dragged: dragged,
                                                handle: handle, old: original, keepAspect: keepAspect && handle.isCorner)
            return rect.intersection(image)
        }
    }

    /// Pixel interi dentro l'immagine; `nil` se il riquadro è più piccolo di un pixel.
    public static func pixelRect(_ rect: CGRect, imageSize: PixelSize) -> PixelRect? {
        let r = rect.standardized
        guard r.minX.isFinite, r.minY.isFinite, r.maxX.isFinite, r.maxY.isFinite else { return nil }
        let minX = Int(r.minX.rounded()), minY = Int(r.minY.rounded())
        let maxX = Int(r.maxX.rounded()), maxY = Int(r.maxY.rounded())
        let pixel = PixelRect(x: minX, y: minY, width: maxX - minX, height: maxY - minY).clamped(to: imageSize)
        return pixel.width >= 1 && pixel.height >= 1 ? pixel : nil
    }

    private static func clamp(_ point: CGPoint, to rect: CGRect) -> CGPoint {
        CGPoint(x: min(max(point.x, rect.minX), rect.maxX), y: min(max(point.y, rect.minY), rect.maxY))
    }
}
```

```swift
    private func handleCrop(_ event: ToolEvent, document: PinxelDocument) -> ToolResult {
        let image = CGRect(origin: .zero, size: document.imageSize.cgSize)
        let current = cropRect ?? image
        switch event {
        case .down(let point, _, _):
            let reach = hitTolerance * 1.5
            if let handle = Handle.boxHandles.first(where: { HitTesting.boxPoint($0, of: current).distance(to: point) <= reach }) {
                cropDrag = (.resize(handle), point, current)
            } else if cropRect != nil, current.contains(point) {
                cropDrag = (.move, point, current)
            } else {
                // Senza un riquadro scelto, trascinare sull'immagine ne disegna uno nuovo.
                cropDrag = (.new, point, current)
            }
            return ToolResult()
        case .drag(let point, let modifiers), .up(let point, let modifiers):
            guard let drag = cropDrag else { return ToolResult() }

            if drag.mode != .new || (rect.width >= dragThreshold && rect.height >= dragThreshold) { cropRect = rect }
```

```swift
import CoreGraphics
import DocumentModel

public enum CutGeometry {
    /// Fascia minima, in pixel: sotto questa un trascinamento è un clic.
    public static let minimumLength = 2

    /// Fascia da togliere trascinando da `start` a `end`: un trascinamento soprattutto verticale toglie righe
    /// (fascia orizzontale), uno orizzontale toglie colonne. `nil` se troppo corta o se toglierebbe tutto.
    public static func cut(from start: CGPoint, to end: CGPoint, imageSize: PixelSize, edge: CutEdge) -> CutOut? {
        let axis: Axis = abs(end.y - start.y) >= abs(end.x - start.x) ? .horizontal : .vertical
        let a = axis == .horizontal ? start.y : start.x
        let b = axis == .horizontal ? end.y : end.x
        let limit = Double(axis == .horizontal ? imageSize.height : imageSize.width)
        let low = Int(max(0, min(a, b)).rounded())
        let high = Int(min(limit, max(a, b)).rounded())
        let length = high - low
        guard length >= minimumLength, length < Int(limit) else { return nil }
        return CutOut(axis: axis, start: low, length: length, edge: edge)
    }
}
```

```swift
import Foundation

/// Cosa possono fare i menu con l'editor in primo piano: quali voci sono attive e come si chiama Annulla.
public struct EditorMenuState: Equatable, Sendable {
    public var hasEditor = false
    public var canEdit = false
    public var isEditingText = false
    public var hasSelection = false
    /// Selezione con almeno un oggetto non bloccato, in un documento modificabile.
    public var hasEditableSelection = false
    public var hasLockedSelection = false
    public var hasUnlockedSelection = false
    public var canUndo = false
    public var canRedo = false
    public var undoActionName = ""
    public var redoActionName = ""

    /// Nessun editor in primo piano.
    public init() {}

    @MainActor
    public init(model: EditorModel) {
        let session = model.session
        hasEditor = true
        canEdit = !session.isReadOnly
        isEditingText = model.editingText != nil
        let selected = session.selectedAnnotations
        hasSelection = !selected.isEmpty
        hasEditableSelection = canEdit && selected.contains { !$0.isLocked }
        hasLockedSelection = canEdit && selected.contains(where: \.isLocked)
        hasUnlockedSelection = hasEditableSelection
        canUndo = session.undoManager.canUndo
        canRedo = session.undoManager.canRedo
        undoActionName = session.undoManager.undoActionName
        redoActionName = session.undoManager.redoActionName
    }

    /// Le voci di modifica senza un editor in primo piano (Preferenze, pannello Salva) o durante la scrittura
    /// di un testo vanno ai campi di testo: restano attive. Altrimenti decide `condition`.
    public func allows(_ condition: Bool) -> Bool {
        !hasEditor || isEditingText || condition
    }

    public var undoTitle: String { title("Annulla", undoActionName) }
    public var redoTitle: String { title("Ripristina", redoActionName) }

    private func title(_ verb: String, _ action: String) -> String {
        guard hasEditor, !isEditingText, let first = action.first else { return verb }
        return "\(verb) \(first.lowercased())\(action.dropFirst())"
    }
}
```

```swift
@MainActor

    @Published private(set) var state = EditorMenuState()

        refresh()

        self.model = nil
        refresh()

            state = EditorMenuState()
            return

        let next = withObservationTracking {
            EditorMenuState(model: model)
        } onChange: { [weak self] in
            Task { @MainActor in self?.refresh() }
        }
        if next != state { state = next }
    }
}
```

```swift
import CoreGraphics
import DocumentModel

/// Fogli del menu Immagine.
public enum EditorSheet: String, Identifiable, Sendable {
    case resizeImage, canvasStyle

    public var id: String { rawValue }
}

/// Valori del foglio Ridimensiona immagine. Le dimensioni restano in 1...`maxImageSide`.
public struct ResizeDraft: Equatable, Sendable {
    public let original: PixelSize
    public private(set) var width: Int
    public private(set) var height: Int
    public var keepsAspect = true

    public init(original: PixelSize) {
        self.original = original
        width = original.width
        height = original.height
    }

    public mutating func setWidth(_ value: Int) {
        width = Self.clamp(value)
        if keepsAspect { height = Self.clamp(Self.scaled(original.height, by: Double(width) / Double(max(original.width, 1)))) }
    }

    public mutating func setHeight(_ value: Int) {
        height = Self.clamp(value)
        if keepsAspect { width = Self.clamp(Self.scaled(original.width, by: Double(height) / Double(max(original.height, 1)))) }
    }

    public mutating func setPercent(_ percent: Double) {
        width = Self.clamp(Self.scaled(original.width, by: percent / 100))
        height = Self.clamp(Self.scaled(original.height, by: percent / 100))
    }

    /// Larghezza rispetto all'originale, in percento arrotondato.
    public var percent: Int {
        Int((Double(width) / Double(max(original.width, 1)) * 100).rounded())
    }

    /// `nil` se le dimensioni non cambiano.
    public var operation: ImageOperation? {
        let size = PixelSize(width: width, height: height)
        return size == original ? nil : .resize(size)
    }

    private static func scaled(_ value: Int, by factor: Double) -> Int {
        let result = (Double(value) * factor).rounded()
        return result.isFinite ? Int(max(min(result, Double(Int32.max)), 0)) : 1
    }

    private static func clamp(_ value: Int) -> Int {
        min(max(value, 1), PinxelDocument.maxImageSide)
    }
}

/// Modifiche al bordo, all'ombra, ai margini e allo sfondo della tela (foglio Bordo, ombra e margini).
public enum CanvasStyleEditing {
    public static let defaultBorder = Border(color: .black, width: 4)
    public static let defaultShadow = Shadow(offset: CGSize(width: 0, height: 8), blur: 24, color: RGBA(red: 0, green: 0, blue: 0, alpha: 0.35))

    /// Margine minimo perché l'ombra non venga tagliata dal bordo della tela.
    public static func paddingNeeded(for shadow: Shadow) -> Double {
        (shadow.blur * 1.5 + max(abs(shadow.offset.width), abs(shadow.offset.height))).rounded(.up)
    }

    /// Accendere l'ombra allarga i margini quanto serve; spegnerla non li stringe.
    public static func settingShadow(_ on: Bool, in style: CanvasStyle) -> CanvasStyle {
        var result = style
        result.shadow = on ? (style.shadow ?? defaultShadow) : nil
        if let shadow = result.shadow { result.padding = max(result.padding, paddingNeeded(for: shadow)) }
        return result
    }

    public static func settingBorder(_ on: Bool, in style: CanvasStyle) -> CanvasStyle {
        var result = style
        result.border = on ? (style.border ?? defaultBorder) : nil
        return result
    }

    public static func settingBackground(_ on: Bool, in style: CanvasStyle) -> CanvasStyle {
        var result = style
        result.backgroundColor = on ? (style.backgroundColor ?? .white) : nil
        return result
    }
}
```

```swift
import CoreGraphics

/// Linea guida da disegnare durante uno spostamento, in coordinate del documento.
public struct GuideLine: Equatable, Sendable {
    public enum Orientation: Sendable {
        case vertical, horizontal
    }

    public var orientation: Orientation
    /// x per le verticali, y per le orizzontali.
    public var position: Double
    public var from: Double
    public var to: Double

    public init(orientation: Orientation, position: Double, from: Double, to: Double) {
        self.orientation = orientation
        self.position = position
        self.from = from
        self.to = to
    }
}

/// Guide magnetiche (spec §6.3): bordi e centri di chi si sposta si agganciano a bordi e centri degli altri.
public enum SmartGuides {
    /// Correzione da aggiungere allo spostamento perché `moving` si allinei alla linea più vicina entro
    /// `tolerance`, per ciascun asse, e le guide che mostrano l'allineamento.
    public static func snap(_ moving: CGRect, to targets: [CGRect], tolerance: Double) -> (offset: CGSize, guides: [GuideLine]) {
        let dx = bestOffset(lines(moving, .vertical), targets.flatMap { lines($0, .vertical) }, tolerance)
        let dy = bestOffset(lines(moving, .horizontal), targets.flatMap { lines($0, .horizontal) }, tolerance)
        let snapped = moving.offsetBy(dx: dx ?? 0, dy: dy ?? 0)
        var guides: [GuideLine] = []
        if dx != nil { guides += self.guides(snapped, targets, .vertical) }
        if dy != nil { guides += self.guides(snapped, targets, .horizontal) }
        return (CGSize(width: dx ?? 0, height: dy ?? 0), guides)
    }

    private static func lines(_ rect: CGRect, _ orientation: GuideLine.Orientation) -> [Double] {
        orientation == .vertical ? [rect.minX, rect.midX, rect.maxX] : [rect.minY, rect.midY, rect.maxY]
    }

    private static func bestOffset(_ values: [Double], _ lines: [Double], _ tolerance: Double) -> Double? {
        var best: Double?
        for value in values {
            for line in lines {
                let distance = line - value
                if abs(distance) <= tolerance, abs(distance) < abs(best ?? .infinity) { best = distance }
            }
        }
        return best
    }

    /// Una guida per ogni linea di `rect` che coincide con una linea di qualche bersaglio, lunga quanto basta
    /// a toccarli tutti.
    private static func guides(_ rect: CGRect, _ targets: [CGRect], _ orientation: GuideLine.Orientation) -> [GuideLine] {
        var result: [GuideLine] = []
        for position in lines(rect, orientation) where !result.contains(where: { abs($0.position - position) < 0.5 }) {
            let matching = targets.filter { target in lines(target, orientation).contains { abs($0 - position) < 0.5 } }
            guard !matching.isEmpty else { continue }
            let all = matching + [rect]
            let from = orientation == .vertical ? all.map(\.minY).min() ?? 0 : all.map(\.minX).min() ?? 0
            let to = orientation == .vertical ? all.map(\.maxY).max() ?? 0 : all.map(\.maxX).max() ?? 0
            result.append(GuideLine(orientation: orientation, position: position, from: from, to: to))
        }
        return result
    }
}
```

```swift
import DocumentModel
import Foundation
import Observation

/// Ultimi 8 stili usati per strumento, salvati nelle preferenze (spec §6.1). Condiviso da tutte le finestre.
@MainActor
@Observable
public final class QuickStyleStore {
    public static let shared = QuickStyleStore()
    public static let limit = 8
    static let defaultsKey = "PinxelQuickStyles"

    public private(set) var styles: [EditorTool: [Style]] = [:]
    @ObservationIgnored private let defaults: UserDefaults

    public init(defaults: UserDefaults = .standard) {
        self.defaults = defaults
        if let data = defaults.data(forKey: Self.defaultsKey),
           let raw = try? JSONDecoder().decode([String: [Style]].self, from: data) {
            for (name, list) in raw {
                if let tool = EditorTool(rawValue: name) { styles[tool] = Array(list.prefix(Self.limit)) }
            }
        }
    }

    public func styles(for tool: EditorTool) -> [Style] {
        styles[tool] ?? []
    }

    /// Mette `style` in cima alla lista dello strumento, senza doppioni.
    public func record(_ style: Style, for tool: EditorTool) {
        var list = styles(for: tool)
        list.removeAll { $0 == style }
        list.insert(style, at: 0)
        if list.count > Self.limit { list.removeLast(list.count - Self.limit) }
        styles[tool] = list
        let raw = Dictionary(uniqueKeysWithValues: styles.map { ($0.key.rawValue, $0.value) })
        if let data = try? JSONEncoder().encode(raw) { defaults.set(data, forKey: Self.defaultsKey) }
    }
}
```

```swift
    }
```

```swift
import CoreGraphics

public enum ImagePlacement {
    /// Riquadro di un'immagine incollata, in pixel del documento: alla stessa densità del documento
    /// (uno screenshot Retina in una cattura Retina mantiene i suoi pixel), ridotta entro l'80% della cattura,
    /// centrata in `center`.
    public static func rect(pixelSize: CGSize, imageScale: Double, documentScale: Double, center: CGPoint, imageSize: CGSize) -> CGRect {
        let factor = documentScale / max(imageScale, 1)
        var width = pixelSize.width * factor
        var height = pixelSize.height * factor
        let shrink = min(1, imageSize.width * 0.8 / max(width, 1), imageSize.height * 0.8 / max(height, 1))
        width = max(1, (width * shrink).rounded())
        height = max(1, (height * shrink).rounded())
        return CGRect(x: (center.x - width / 2).rounded(), y: (center.y - height / 2).rounded(), width: width, height: height)
    }
}
```

```swift
import Foundation

public enum TemporaryFiles {
    public static var root: URL {
        FileManager.default.temporaryDirectory.appendingPathComponent("Pinxel", isDirectory: true)
    }

    /// URL di `fileName` in una cartella nuova: due file con lo stesso nome non si sovrascrivono mai,
    /// e chi li riceve (Finder, Mail, Messaggi) vede il nome pulito.
    public static func uniqueURL(fileName: String, root: URL = TemporaryFiles.root, fileManager: FileManager = .default) throws -> URL {
        let folder = root.appendingPathComponent(UUID().uuidString, isDirectory: true)
        try fileManager.createDirectory(at: folder, withIntermediateDirectories: true)
        return folder.appendingPathComponent(fileName)
    }
}
```

```swift
    /// Toglie le scorciatoie senza ⌃, ⌥ o ⌘ e quelle uguali a un'azione precedente: tornano alle predefinite.
    public mutating func sanitizeHotKeys() {
        var seen = Set<KeyCombo>()
        for action in HotKeyAction.allCases {
            guard let combo = hotKeys[action] else { continue }
            if !combo.hasModifier || seen.contains(combo) {
                hotKeys[action] = nil
            } else {
                seen.insert(combo)
            }
        }
    }
```
