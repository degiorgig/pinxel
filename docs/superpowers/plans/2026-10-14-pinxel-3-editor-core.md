# Pinxel 3 — Editor Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the read-only viewer with a real editor: a zoomable canvas, the selection tool (select, move, resize, rotate, duplicate, nudge, delete, arrange, lock), the drawing tools arrow / line / shape / pen / highlighter / step / blur-pixelate, a properties inspector, full undo/redo through `NSDocument`, save, copy/paste, Export… and Share.

**Architecture:** A new PinxelKit target `EditorUI` holds everything testable: `Viewport` (zoom/pan math), `HitTesting` and `AnnotationGeometry` (handles, hit areas, move/resize/rotate math, rotation-aware), `ToolController` (the tool state machine: abstract events in, previews and `EditCommand`s out, no views), `EditorSession` (document + selection + gesture preview + `UndoManager` integration with coalescing), `EditorModel` (active tool, tool styles, inspector logic) and `CanvasView` (an AppKit `NSView` that draws through `DocumentRenderer` and turns mouse/keyboard into tool events). The app target hosts it in a SwiftUI window (native unified toolbar, `.inspector` side panel) owned by `PinxelFileDocument`, and adds menus, export and share.

**Tech Stack:** Swift 6, macOS 15+, Xcode 27, XcodeGen 2.46, AppKit (`NSView`, `NSDocument`, `NSSavePanel`), SwiftUI (`NSHostingController` with toolbar bridging, `.inspector`, `ShareLink`), Observation, Core Graphics, Swift Testing (package), XCTest/XCUITest (app).

**Spec:** `docs/superpowers/specs/2026-10-14-pinxel-capture-editor-design.md` (sections 1, 5.4, 6.1–6.3, 9, 10, 11). Builds on plan 1 (`docs/superpowers/plans/2026-10-14-pinxel-1-core.md`) and plan 2 (`docs/superpowers/plans/2026-10-14-pinxel-2-app-capture.md`), both merged.

**Scope split (ruling at plan time):** spec §6 is too large for one plan. This plan ("editor core") delivers the canvas, the selection tool, eight drawing tools, the inspector, undo, save, copy/paste, export and share. Plan 4 ("editor tools") will add text and callout editing on the canvas, magnifier, crop, cut-out, the Image menu (resize, border, shadow, padding), magnetic guides, quick styles, pasting images, toolbar drag-out / proxy icon, and the read-only / recovery UX. Cost if wrong: the editor ships in two steps; nothing in this plan blocks plan 4.

## Global Constraints

- Platform floor `macOS 15`; Swift 6 language mode in package and app; strict concurrency, no warnings.
- No third-party dependencies. `Pinxel.xcodeproj` is generated by XcodeGen and git-ignored; after changing `project.yml` run `xcodegen generate`.
- `EditorUI` depends only on `DocumentModel` and `Rendering` (spec §4). `Persistence` stays out of it; export lives in `AppCore` and the app.
- All drawing goes through `DocumentRenderer.render` (spec §9): the canvas never draws annotations by itself.
- Document coordinates: pixels of the image after image operations, origin top-left, y down (spec §3, §5.1). Canvas coordinates = document coordinates + `canvasStyle.padding`. View coordinates: points, flipped view (origin top-left).
- Zoom 100% = one image pixel per screen pixel, i.e. `pointsPerPixel = zoom / document.scale` (spec §1 criterion 3).
- One continuous interaction (drag, resize, rotate, slider drag) = one command, registered on mouse-up (spec §5.4). During the gesture the canvas shows an unregistered preview.
- Consecutive keyboard nudges on the same objects within 1 s merge into one command (spec §5.4). Arrows move 1 px, `⇧` 10 px, in document pixels.
- Undo/redo uses the document's `UndoManager` (menu, `⌘Z`, `⇧⌘Z`), unlimited, not persisted.
- Locked annotations can be selected but never moved, resized, rotated, restyled or deleted. Read-only documents accept no edits at all.
- Tool shortcuts (single key, no modifiers): V select, A arrow, L line, R shape, P pen, H highlighter, S step, B blur/pixelate (spec §6.2).
- Private pasteboard type `com.degiorgi.pinxel.annotations` (spec §6.3).
- User-visible strings are Italian. Logging subsystem `com.degiorgi.pinxel`.
- Apple design (from the `apple-design` skill, applied to AppKit): feedback on mouse-down, 1:1 tracking that keeps the grab offset, zoom anchored at the pointer, native controls and system colors (light/dark), SF Symbols with help tags that name the shortcut, no animation that blocks input.

## Review Focus

1. **Rotated annotations**: hit area, handles and resize must stay where the user sees them; resizing a rotated box keeps the opposite corner fixed on screen → tests in Task 2 (`rotatedShapeUsesRotatedArea`) and Task 3 (`rotatedResizeKeepsOppositeCornerOnScreen`).
2. **Retina documents with padding**: mouse → document mapping must include `scale` and `canvasStyle.padding`, or every edit lands offset → test in Task 9 (`mapsViewPointsWithPaddingAndRetinaScale`).
3. **Undo after mixed bursts** (nudges, then a drag, then more nudges; slider and color drags): each burst is one undo step and undoing everything restores the original document → tests in Task 4 (`anotherCommandBreaksCoalescing`, `undoingEverythingRestoresTheOriginalDocument`) and Task 7 (`colorDragCoalescesIntoOneUndo`).
4. **Locked annotations and read-only documents** through every path (drag, handles, delete key, nudge, inspector, lock menu, paste): never modified → tests in Task 4 (`readOnlySessionIgnoresEdits`), Task 5 (`lockedAnnotationIsSelectableButNotMovedOrDeleted`), Task 7 (`styleChangesSkipLockedAnnotations`), Task 9 (`readOnlyCanvasOnlySelects`).
5. **Degenerate gestures**: a click with a drawing tool, a zero-size rectangle, a one-point pen stroke, resizing past the opposite edge or to zero width, `Esc` in the middle of a drag → tests in Task 3 (`draggingPastTheAnchorFlips`, `resizeKeepsMinimumSize`), Task 5 (`escapeCancelsTheGesture`), Task 6 (`tinyDragsCreateNothing`).

`PinxelKit/Sources/EditorUI/Viewport.swift`:

```swift
import CoreGraphics
import Foundation

/// Zoom e scorrimento del canvas. Le coordinate della vista sono in punti con origine in alto a sinistra
/// (vista capovolta); quelle della tela in pixel del documento, padding incluso.
public struct Viewport: Equatable, Sendable {
    public static let zoomLevels: [Double] = [0.1, 0.25, 0.5, 0.75, 1, 1.5, 2, 3, 4, 6, 8]
    public static let zoomRange: ClosedRange<Double> = 0.1...8

    /// 1 = 100%: un pixel dell'immagine occupa un pixel dello schermo (1/scale punti).
    public private(set) var zoom: Double
    /// Posizione nella vista dell'origine della tela.
    public var origin: CGPoint
    public let documentScale: Double

    public init(documentScale: Double, zoom: Double = 1, origin: CGPoint = .zero) {
        self.documentScale = documentScale > 0 && documentScale.isFinite ? documentScale : 1
        self.zoom = Self.clamp(zoom)
        self.origin = origin
    }

    /// Punti della vista per pixel del documento.
    public var pointsPerPixel: Double { zoom / documentScale }

    public func viewPoint(fromCanvas point: CGPoint) -> CGPoint {
        CGPoint(x: origin.x + point.x * pointsPerPixel, y: origin.y + point.y * pointsPerPixel)
    }

    public func canvasPoint(fromView point: CGPoint) -> CGPoint {
        CGPoint(x: (point.x - origin.x) / pointsPerPixel, y: (point.y - origin.y) / pointsPerPixel)
    }

    public func viewRect(fromCanvas rect: CGRect) -> CGRect {
        let topLeft = viewPoint(fromCanvas: rect.origin)
        return CGRect(x: topLeft.x, y: topLeft.y, width: rect.width * pointsPerPixel, height: rect.height * pointsPerPixel)
    }

    /// Cambia lo zoom tenendo fermo sotto `anchor` (punto della vista) il punto della tela che c'era.
    public mutating func setZoom(_ newZoom: Double, anchor: CGPoint) {
        let fixed = canvasPoint(fromView: anchor)
        zoom = Self.clamp(newZoom)
        origin = CGPoint(x: anchor.x - fixed.x * pointsPerPixel, y: anchor.y - fixed.y * pointsPerPixel)
    }

    public mutating func zoomIn(anchor: CGPoint) {
        setZoom(Self.zoomLevels.first { $0 > zoom + 1e-9 } ?? Self.zoomRange.upperBound, anchor: anchor)
    }

    public mutating func zoomOut(anchor: CGPoint) {
        setZoom(Self.zoomLevels.last { $0 < zoom - 1e-9 } ?? Self.zoomRange.lowerBound, anchor: anchor)
    }

    /// Adatta la tela alla vista, centrata, senza ingrandire oltre il 100%.
    public mutating func fit(canvasSize: CGSize, in viewSize: CGSize, margin: Double = 20) {
        guard canvasSize.width > 0, canvasSize.height > 0 else { return }
        let availableWidth = max(viewSize.width - 2 * margin, 1)
        let availableHeight = max(viewSize.height - 2 * margin, 1)
        let fitting = min(availableWidth / canvasSize.width, availableHeight / canvasSize.height) * documentScale
        zoom = Self.clamp(min(1, fitting))
        center(canvasSize: canvasSize, in: viewSize)
    }

    public mutating func actualSize(canvasSize: CGSize, in viewSize: CGSize) {
        zoom = 1
        center(canvasSize: canvasSize, in: viewSize)
    }

    public mutating func pan(by delta: CGSize) {
        origin.x += delta.width
        origin.y += delta.height
    }

    private mutating func center(canvasSize: CGSize, in viewSize: CGSize) {
        origin = CGPoint(
            x: (viewSize.width - canvasSize.width * pointsPerPixel) / 2,
            y: (viewSize.height - canvasSize.height * pointsPerPixel) / 2
        )
    }

    private static func clamp(_ value: Double) -> Double {
        guard value.isFinite else { return 1 }
        return min(max(value, zoomRange.lowerBound), zoomRange.upperBound)
    }
}
```

**Interfaces:**
- Consumes: `Annotation`, `Annotation.bounds`, `CGRect.bounding(_:)` (DocumentModel).
- Produces:
  - `extension CGPoint { public func rotated(around:by:) -> CGPoint; func distance(to:) -> Double; func distance(toSegment:_:) -> Double }`
  - `public enum Handle: Hashable, Sendable { topLeft, top, topRight, right, bottomRight, bottom, bottomLeft, left, lineStart, lineEnd, rotation }` with `boxHandles`, `isCorner`, `opposite`, `movesX`, `movesY`.
  - `public enum HitTesting` with `annotation(at:in:tolerance:) -> Annotation?`, `contains(_:point:tolerance:) -> Bool`, `ids(intersecting:in:) -> Set<UUID>`, `worldBounds(_:) -> CGRect`, `handles(for:rotationOffset:) -> [(handle: Handle, point: CGPoint)]`, `handle(at:for:tolerance:rotationOffset:) -> Handle?`, `boxPoint(_:of:) -> CGPoint`.

Hit rules: lines, arrows, pen and highlighter are hit near their stroke (`tolerance + lineWidth / 2`); an unfilled shape only near its outline (so clicks inside reach what is underneath); a filled shape, text, callout, step, blur, pixelate and placed image anywhere inside; a magnifier inside its source or target; `unknown` never. Points are rotated into the annotation's local frame first, around the center of `bounds` (same convention as `AnnotationRenderer`).

```swift
import CoreGraphics
import Foundation

extension CGPoint {
    /// Il punto ruotato di `angle` radianti attorno a `center`, nello spazio con l'asse y verso il basso
    /// (stessa convenzione di `AnnotationRenderer`).
    public func rotated(around center: CGPoint, by angle: Double) -> CGPoint {
        guard angle != 0 else { return self }
        let dx = x - center.x, dy = y - center.y
        let cosine = cos(angle), sine = sin(angle)
        return CGPoint(x: center.x + dx * cosine - dy * sine, y: center.y + dx * sine + dy * cosine)
    }

    func distance(to other: CGPoint) -> Double {
        hypot(x - other.x, y - other.y)
    }

    func distance(toSegment a: CGPoint, _ b: CGPoint) -> Double {
        let dx = b.x - a.x, dy = b.y - a.y
        let lengthSquared = dx * dx + dy * dy
        guard lengthSquared > 0 else { return distance(to: a) }
        let t = max(0, min(1, ((x - a.x) * dx + (y - a.y) * dy) / lengthSquared))
        return distance(to: CGPoint(x: a.x + t * dx, y: a.y + t * dy))
    }
}

extension CGRect {
    var center: CGPoint { CGPoint(x: midX, y: midY) }
}
```

```swift
import CoreGraphics
import DocumentModel
import Foundation

/// Maniglie di modifica di un'annotazione selezionata.
public enum Handle: Hashable, Sendable {
    case topLeft, top, topRight, right, bottomRight, bottom, bottomLeft, left
    case lineStart, lineEnd
    case rotation

    /// Le otto maniglie del riquadro, in senso orario dall'angolo in alto a sinistra.
    public static let boxHandles: [Handle] = [.topLeft, .top, .topRight, .right, .bottomRight, .bottom, .bottomLeft, .left]

    public var isCorner: Bool { [.topLeft, .topRight, .bottomRight, .bottomLeft].contains(self) }

    /// La maniglia che resta ferma mentre si trascina questa.
    public var opposite: Handle {
        switch self {
        case .topLeft: .bottomRight
        case .top: .bottom
        case .topRight: .bottomLeft
        case .right: .left
        case .bottomRight: .topLeft
        case .bottom: .top
        case .bottomLeft: .topRight
        case .left: .right
        case .lineStart: .lineEnd
        case .lineEnd: .lineStart
        case .rotation: .rotation
        }
    }

    public var movesX: Bool { [.topLeft, .topRight, .bottomRight, .bottomLeft, .left, .right].contains(self) }
    public var movesY: Bool { [.topLeft, .topRight, .bottomRight, .bottomLeft, .top, .bottom].contains(self) }
}

public enum HitTesting {
    /// L'annotazione più in alto sotto `point` (coordinate del documento). `tolerance` è in pixel del documento.
    public static func annotation(at point: CGPoint, in annotations: [Annotation], tolerance: Double) -> Annotation? {
        annotations.last { contains($0, point: point, tolerance: tolerance) }
    }

    public static func contains(_ annotation: Annotation, point: CGPoint, tolerance: Double) -> Bool {
        let bounds = annotation.bounds
        guard !bounds.isNull else { return false }
        let local = point.rotated(around: bounds.center, by: -annotation.rotation)
        let reach = tolerance + annotation.style.lineWidth / 2
        switch annotation.kind {
        case .arrow(let data):
            return local.distance(toSegment: data.line.start, data.line.end) <= reach
        case .line(let data):
            return local.distance(toSegment: data.line.start, data.line.end) <= reach
        case .pen(let data):
            return polylineDistance(from: local, to: data.path.points) <= reach
        case .highlight(let data):
            return polylineDistance(from: local, to: data.path.points) <= reach
        case .shape(let data):
            let rect = data.rect.standardized
            if annotation.style.fill != nil {
                return shapeContains(data.shape, rect: rect, point: local, tolerance: tolerance)
            }
            return outlineDistance(data.shape, rect: rect, point: local) <= reach
        case .magnifier(let data):
            return data.source.standardized.insetBy(dx: -tolerance, dy: -tolerance).contains(local)
                || data.target.standardized.insetBy(dx: -tolerance, dy: -tolerance).contains(local)
        case .text, .callout, .step, .blur, .pixelate, .image:
            return bounds.insetBy(dx: -tolerance, dy: -tolerance).contains(local)
        case .unknown:
            return false
        }
    }

    /// ID delle annotazioni il cui riquadro (ruotato) interseca `rect`.
    public static func ids(intersecting rect: CGRect, in annotations: [Annotation]) -> Set<UUID> {
        let area = rect.standardized
        return Set(annotations.filter { annotation in
            let bounds = worldBounds(annotation)
            return !bounds.isNull && bounds.intersects(area)
        }.map(\.id))
    }

    /// Riquadro allineato agli assi che contiene l'annotazione ruotata.
    public static func worldBounds(_ annotation: Annotation) -> CGRect {
        let bounds = annotation.bounds
        guard !bounds.isNull, annotation.rotation != 0 else { return bounds }
        return .bounding(corners(of: bounds).map { $0.rotated(around: bounds.center, by: annotation.rotation) })
    }

    /// Maniglie in coordinate del documento. `rotationOffset` è la distanza della maniglia di rotazione
    /// sopra il riquadro. Le annotazioni bloccate non hanno maniglie.
    public static func handles(for annotation: Annotation, rotationOffset: Double) -> [(handle: Handle, point: CGPoint)] {
        guard !annotation.isLocked else { return [] }
        let bounds = annotation.bounds
        guard !bounds.isNull else { return [] }
        var local: [(handle: Handle, point: CGPoint)]
        switch annotation.kind {
        case .arrow(let data):
            local = [(.lineStart, data.line.start), (.lineEnd, data.line.end)]
        case .line(let data):
            local = [(.lineStart, data.line.start), (.lineEnd, data.line.end)]
        case .step:
            local = Handle.boxHandles.filter(\.isCorner).map { ($0, boxPoint($0, of: bounds)) }
        case .unknown:
            return []
        default:
            local = Handle.boxHandles.map { ($0, boxPoint($0, of: bounds)) }
            local.append((.rotation, CGPoint(x: bounds.midX, y: bounds.minY - rotationOffset)))
        }
        return local.map { ($0.handle, $0.point.rotated(around: bounds.center, by: annotation.rotation)) }
    }

    public static func handle(at point: CGPoint, for annotation: Annotation, tolerance: Double, rotationOffset: Double) -> Handle? {
        handles(for: annotation, rotationOffset: rotationOffset)
            .filter { $0.point.distance(to: point) <= tolerance }
            .min { $0.point.distance(to: point) < $1.point.distance(to: point) }?
            .handle
    }

    /// Posizione di una maniglia del riquadro su `rect` (non ruotato).
    public static func boxPoint(_ handle: Handle, of rect: CGRect) -> CGPoint {
        switch handle {
        case .topLeft: CGPoint(x: rect.minX, y: rect.minY)
        case .top: CGPoint(x: rect.midX, y: rect.minY)
        case .topRight: CGPoint(x: rect.maxX, y: rect.minY)
        case .right: CGPoint(x: rect.maxX, y: rect.midY)
        case .bottomRight: CGPoint(x: rect.maxX, y: rect.maxY)
        case .bottom: CGPoint(x: rect.midX, y: rect.maxY)
        case .bottomLeft: CGPoint(x: rect.minX, y: rect.maxY)
        case .left: CGPoint(x: rect.minX, y: rect.midY)
        case .lineStart, .lineEnd, .rotation: rect.center
        }
    }

    static func corners(of rect: CGRect) -> [CGPoint] {
        [CGPoint(x: rect.minX, y: rect.minY), CGPoint(x: rect.maxX, y: rect.minY),
         CGPoint(x: rect.maxX, y: rect.maxY), CGPoint(x: rect.minX, y: rect.maxY)]
    }

    private static func polylineDistance(from point: CGPoint, to points: [CGPoint]) -> Double {
        guard let first = points.first else { return .infinity }
        guard points.count > 1 else { return point.distance(to: first) }
        return zip(points, points.dropFirst()).map { point.distance(toSegment: $0, $1) }.min() ?? .infinity
    }

    private static func shapeContains(_ shape: ShapeType, rect: CGRect, point: CGPoint, tolerance: Double) -> Bool {
        switch shape {
        case .rectangle, .roundedRectangle:
            return rect.insetBy(dx: -tolerance, dy: -tolerance).contains(point)
        case .ellipse:
            let radiusX = rect.width / 2, radiusY = rect.height / 2
            guard radiusX > 0, radiusY > 0 else { return false }
            let nx = (point.x - rect.midX) / radiusX, ny = (point.y - rect.midY) / radiusY
            return (nx * nx + ny * ny).squareRoot() <= 1 + tolerance / min(radiusX, radiusY)
        }
    }

    private static func outlineDistance(_ shape: ShapeType, rect: CGRect, point: CGPoint) -> Double {
        switch shape {
        case .rectangle, .roundedRectangle:
            if rect.contains(point) {
                return min(point.x - rect.minX, rect.maxX - point.x, point.y - rect.minY, rect.maxY - point.y)
            }
            let dx = max(rect.minX - point.x, 0, point.x - rect.maxX)
            let dy = max(rect.minY - point.y, 0, point.y - rect.maxY)
            return hypot(dx, dy)
        case .ellipse:
            let radiusX = rect.width / 2, radiusY = rect.height / 2
            guard radiusX > 0, radiusY > 0 else { return point.distance(to: rect.center) }
            let nx = (point.x - rect.midX) / radiusX, ny = (point.y - rect.midY) / radiusY
            return abs((nx * nx + ny * ny).squareRoot() - 1) * min(radiusX, radiusY)
        }
    }
}
```

```swift
import CoreGraphics
import DocumentModel
import Foundation

/// Trasformazioni geometriche dei gesti dell'editor. Tutte le coordinate sono del documento.
public enum AnnotationGeometry {
    /// Lato minimo di un riquadro ridimensionato, in pixel del documento.
    public static let minimumSize: Double = 1

    public static func moved(_ annotation: Annotation, by delta: CGSize) -> Annotation {
        let dx = delta.width, dy = delta.height
        guard dx != 0 || dy != 0 else { return annotation }
        return annotation.transformed(by: PointMapping { CGPoint(x: $0.x + dx, y: $0.y + dy) })
    }

    /// Ridimensiona trascinando `handle` fino a `point`. Per le annotazioni ruotate il punto opposto
    /// resta fermo sullo schermo.
    public static func resized(_ annotation: Annotation, handle: Handle, to point: CGPoint, keepAspect: Bool) -> Annotation {
        switch handle {
        case .lineStart, .lineEnd: return movingEndpoint(annotation, handle, to: point, constrain: keepAspect)
        case .rotation: return annotation
        default: break
        }
        let old = annotation.bounds
        guard !old.isNull else { return annotation }
        let local = point.rotated(around: old.center, by: -annotation.rotation)
        let anchor = HitTesting.boxPoint(handle.opposite, of: old)
        var isStep = false
        if case .step = annotation.kind { isStep = true }
        let target = frame(anchor: anchor, dragged: local, handle: handle, old: old,
                           keepAspect: (keepAspect || isStep) && handle.isCorner)

        let scaleX = old.width > 0 ? target.width / old.width : 1
        let scaleY = old.height > 0 ? target.height / old.height : 1
        let oldMinX = old.minX, oldMinY = old.minY, newMinX = target.minX, newMinY = target.minY
        let mapping = PointMapping(lengthScale: (scaleX * scaleY).squareRoot()) { p in
            CGPoint(x: newMinX + (p.x - oldMinX) * scaleX, y: newMinY + (p.y - oldMinY) * scaleY)
        }
        var result = annotation.transformed(by: mapping)
        if annotation.rotation != 0 {
            // Il centro di rotazione si è spostato: trasla perché il punto fermo resti dov'era sullo schermo.
            let before = anchor.rotated(around: old.center, by: annotation.rotation)
            let after = anchor.rotated(around: result.bounds.center, by: annotation.rotation)
            result = moved(result, by: CGSize(width: before.x - after.x, height: before.y - after.y))
        }
        return result
    }

    /// Ruota attorno al centro verso il puntatore; con `snap` a passi di 15°.
    public static func rotated(_ annotation: Annotation, pointer: CGPoint, snap: Bool) -> Annotation {
        let bounds = annotation.bounds
        guard !bounds.isNull else { return annotation }
        // La maniglia sta sopra il centro: puntatore in alto = rotazione zero.
        var angle = atan2(pointer.y - bounds.midY, pointer.x - bounds.midX) + .pi / 2
        if snap {
            let step = Double.pi / 12
            angle = (angle / step).rounded() * step
        }
        var copy = annotation
        copy.rotation = normalized(angle)
        return copy
    }

    /// `point` portato sulla direzione multipla di 45° più vicina, alla stessa distanza da `origin`.
    public static func constrained45(from origin: CGPoint, to point: CGPoint) -> CGPoint {
        let dx = point.x - origin.x, dy = point.y - origin.y
        let length = hypot(dx, dy)
        guard length > 0 else { return point }
        let step = Double.pi / 4
        let angle = (atan2(dy, dx) / step).rounded() * step
        return CGPoint(x: origin.x + length * cos(angle), y: origin.y + length * sin(angle))
    }

    /// Angolo opposto di un quadrato con un vertice in `origin`, verso `point`.
    public static func squared(from origin: CGPoint, to point: CGPoint) -> CGPoint {
        let dx = point.x - origin.x, dy = point.y - origin.y
        let side = max(abs(dx), abs(dy))
        return CGPoint(x: origin.x + (dx < 0 ? -side : side), y: origin.y + (dy < 0 ? -side : side))
    }

    static func frame(anchor: CGPoint, dragged: CGPoint, handle: Handle, old: CGRect, keepAspect: Bool) -> CGRect {
        var minX = old.minX, maxX = old.maxX, minY = old.minY, maxY = old.maxY
        if handle.movesX {
            minX = min(anchor.x, dragged.x)
            maxX = max(anchor.x, dragged.x)
            if maxX - minX < minimumSize {
                if dragged.x >= anchor.x { minX = anchor.x; maxX = anchor.x + minimumSize } else { maxX = anchor.x; minX = anchor.x - minimumSize }
            }
        }
        if handle.movesY {
            minY = min(anchor.y, dragged.y)
            maxY = max(anchor.y, dragged.y)
            if maxY - minY < minimumSize {
                if dragged.y >= anchor.y { minY = anchor.y; maxY = anchor.y + minimumSize } else { maxY = anchor.y; minY = anchor.y - minimumSize }
            }
        }
        if keepAspect, old.width > 0, old.height > 0 {
            let scale = max((maxX - minX) / old.width, (maxY - minY) / old.height)
            let width = old.width * scale, height = old.height * scale
            if dragged.x >= anchor.x { minX = anchor.x; maxX = anchor.x + width } else { maxX = anchor.x; minX = anchor.x - width }
            if dragged.y >= anchor.y { minY = anchor.y; maxY = anchor.y + height } else { maxY = anchor.y; minY = anchor.y - height }
        }
        return CGRect(x: minX, y: minY, width: maxX - minX, height: maxY - minY)
    }

    private static func movingEndpoint(_ annotation: Annotation, _ handle: Handle, to point: CGPoint, constrain: Bool) -> Annotation {
        func update(_ line: LineGeometry) -> LineGeometry {
            var line = line
            if handle == .lineStart {
                line.start = constrain ? constrained45(from: line.end, to: point) : point
            } else {
                line.end = constrain ? constrained45(from: line.start, to: point) : point
            }
            return line
        }
        var copy = annotation
        switch annotation.kind {
        case .arrow(var data):
            data.line = update(data.line)
            copy.kind = .arrow(data)
        case .line(var data):
            data.line = update(data.line)
            copy.kind = .line(data)
        default:
            break
        }
        return copy
    }

    private static func normalized(_ angle: Double) -> Double {
        var value = angle.truncatingRemainder(dividingBy: 2 * .pi)
        if value > .pi { value -= 2 * .pi } else if value <= -.pi { value += 2 * .pi }
        return value
    }
}
```

```swift
import CoreGraphics
import DocumentModel
import Foundation
import Observation
import Rendering

/// Un passo della cronologia. È il bersaglio registrato nell'`UndoManager`; la fusione dei comandi
/// ravvicinati sostituisce il comando nella scatola senza registrare un nuovo passo.
@MainActor
final class CommandBox {
    var command: any EditCommand

    init(_ command: any EditCommand) {
        self.command = command
    }
}

/// Stato di un editor: documento, selezione, anteprima del gesto in corso, annulla/ripeti.
@MainActor
@Observable
public final class EditorSession {
    public static let coalescingInterval: TimeInterval = 1

    public private(set) var document: PinxelDocument
    public var selection: Set<UUID> = []
    /// Annotazioni mostrate al posto di quelle del documento durante un gesto (non registrate).
    public var preview: [Annotation]?
    public let isReadOnly: Bool

    @ObservationIgnored public let assets: any AssetProvider
    @ObservationIgnored public let undoManager: UndoManager
    @ObservationIgnored var now: () -> Date = { Date() }
    @ObservationIgnored private var lastBox: CommandBox?
    @ObservationIgnored private var coalescing: (key: String, date: Date)?

    public init(document: PinxelDocument, assets: any AssetProvider, undoManager: UndoManager = UndoManager(), isReadOnly: Bool = false) {
        self.document = document
        self.assets = assets
        self.undoManager = undoManager
        self.isReadOnly = isReadOnly
    }

    public var displayedAnnotations: [Annotation] { preview ?? document.annotations }

    public var selectedAnnotations: [Annotation] {
        document.annotations.filter { selection.contains($0.id) }
    }

    /// Esegue e registra un comando. Con `coalescingKey`, un `UpdateAnnotations` che segue entro 1 s
    /// un altro con la stessa chiave sugli stessi oggetti si annulla insieme a lui.
    public func perform(_ command: any EditCommand, coalescingKey: String? = nil) {
        guard !isReadOnly else { return }
        preview = nil
        if let key = coalescingKey, let box = lastBox, let last = coalescing, last.key == key,
           now().timeIntervalSince(last.date) < Self.coalescingInterval,
           let previous = box.command as? UpdateAnnotations,
           let next = command as? UpdateAnnotations,
           let merged = previous.merged(with: next) {
            next.apply(to: &document)
            box.command = merged
            coalescing = (key, now())
            pruneSelection()
            return
        }
        command.apply(to: &document)
        let box = CommandBox(command)
        if undoManager.groupsByEvent {
            registerUndo(box)
        } else {
            undoManager.beginUndoGrouping()
            registerUndo(box)
            undoManager.endUndoGrouping()
        }
        lastBox = box
        coalescing = coalescingKey.map { ($0, now()) }
        pruneSelection()
    }

    /// Sposta le annotazioni selezionate e non bloccate; spostamenti ravvicinati si annullano insieme.
    public func nudge(by delta: CGSize) {
        let movable = selectedAnnotations.filter { !$0.isLocked }
        guard !movable.isEmpty else { return }
        let moved = movable.map { AnnotationGeometry.moved($0, by: delta) }
        perform(UpdateAnnotations(name: "Sposta", before: movable, after: moved), coalescingKey: "nudge")
    }

    private func registerUndo(_ box: CommandBox) {
        undoManager.registerUndo(withTarget: box) { [weak self] box in
            MainActor.assumeIsolated { self?.undo(box) }
        }
        undoManager.setActionName(box.command.name)
    }

    private func undo(_ box: CommandBox) {
        box.command.revert(on: &document)
        finishHistoryStep()
        undoManager.registerUndo(withTarget: box) { [weak self] box in
            MainActor.assumeIsolated { self?.redo(box) }
        }
        undoManager.setActionName(box.command.name)
    }

    private func redo(_ box: CommandBox) {
        box.command.apply(to: &document)
        finishHistoryStep()
        registerUndo(box)
    }

    private func finishHistoryStep() {
        preview = nil
        lastBox = nil
        coalescing = nil
        pruneSelection()
    }

    private func pruneSelection() {
        let ids = Set(document.annotations.map(\.id))
        if !selection.isSubset(of: ids) { selection.formIntersection(ids) }
    }
}
```

```swift
import CoreGraphics
import DocumentModel
import Foundation

public struct ToolModifiers: OptionSet, Sendable {
    public let rawValue: Int
    public init(rawValue: Int) { self.rawValue = rawValue }

    public static let shift = ToolModifiers(rawValue: 1)
    public static let option = ToolModifiers(rawValue: 2)
    public static let command = ToolModifiers(rawValue: 4)
}

public enum ToolKey: Sendable {
    case delete, escape, left, right, up, down
}

/// Eventi astratti in coordinate del documento.
public enum ToolEvent: Sendable {
    case down(CGPoint, ToolModifiers, clickCount: Int)
    case drag(CGPoint, ToolModifiers)
    case up(CGPoint, ToolModifiers)
    case key(ToolKey, ToolModifiers)
}

public struct ToolResult {
    /// Annotazioni da mostrare al posto del documento; `nil` = mostra il documento.
    public var preview: [Annotation]?
    public var command: (any EditCommand)?
    /// Nuova selezione; `nil` = invariata.
    public var selection: Set<UUID>?
    public var marquee: CGRect?
    public var nudge: CGSize?

    public init(preview: [Annotation]? = nil, command: (any EditCommand)? = nil, selection: Set<UUID>? = nil,
                marquee: CGRect? = nil, nudge: CGSize? = nil) {
        self.preview = preview
        self.command = command
        self.selection = selection
        self.marquee = marquee
        self.nudge = nudge
    }
}

/// Macchina a stati degli strumenti: riceve eventi in coordinate del documento e restituisce anteprime
/// e comandi. Non conosce viste né finestre (spec §6.3).
public final class ToolController {
    public var tool: EditorTool = .select {
        didSet { if tool != oldValue { gesture = .idle } }
    }
    public var styles = ToolStyles()
    /// Distanze in pixel del documento; il canvas le aggiorna con lo zoom.
    public var hitTolerance: Double = 4
    public var rotationHandleOffset: Double = 30
    public var dragThreshold: Double = 3
    var makeID: () -> UUID = { UUID() }

    private enum Gesture {
        case idle
        case marquee(start: CGPoint, base: Set<UUID>)
        case move(start: CGPoint, originals: [Annotation], copyIDs: [UUID]?, started: Bool)
        case resize(Handle, original: Annotation)
        case rotate(original: Annotation)
        case create(start: CGPoint, id: UUID, points: [CGPoint])
    }

    private var gesture: Gesture = .idle

    public init() {}

    public var isGestureActive: Bool {
        if case .idle = gesture { return false }
        return true
    }

    public func handle(_ event: ToolEvent, document: PinxelDocument, selection: Set<UUID>) -> ToolResult {
        if case .key(let key, let modifiers) = event {
            return handleKey(key, modifiers, document: document, selection: selection)
        }
        return tool == .select
            ? handleSelect(event, document: document, selection: selection)
            : handleCreate(event, document: document)
    }

    // MARK: Tastiera

    private func handleKey(_ key: ToolKey, _ modifiers: ToolModifiers, document: PinxelDocument, selection: Set<UUID>) -> ToolResult {
        let step: Double = modifiers.contains(.shift) ? 10 : 1
        switch key {
        case .escape:
            if isGestureActive {
                gesture = .idle
                return ToolResult()
            }
            return ToolResult(selection: [])
        case .delete:
            let ids = Set(document.annotations.filter { selection.contains($0.id) && !$0.isLocked }.map(\.id))
            guard !ids.isEmpty else { return ToolResult() }
            return ToolResult(command: DeleteAnnotations(ids: ids, in: document))
        case .left: return ToolResult(nudge: CGSize(width: -step, height: 0))
        case .right: return ToolResult(nudge: CGSize(width: step, height: 0))
        case .up: return ToolResult(nudge: CGSize(width: 0, height: -step))
        case .down: return ToolResult(nudge: CGSize(width: 0, height: step))
        }
    }

    // MARK: Selezione

    private func handleSelect(_ event: ToolEvent, document: PinxelDocument, selection: Set<UUID>) -> ToolResult {
        let annotations = document.annotations
        switch event {
        case .down(let point, let modifiers, _):
            if selection.count == 1, let selected = annotations.first(where: { selection.contains($0.id) }),
               let handle = HitTesting.handle(at: point, for: selected, tolerance: hitTolerance, rotationOffset: rotationHandleOffset) {
                gesture = handle == .rotation ? .rotate(original: selected) : .resize(handle, original: selected)
                return ToolResult()
            }
            if let hit = HitTesting.annotation(at: point, in: annotations, tolerance: hitTolerance) {
                var newSelection = selection
                if modifiers.contains(.shift) {
                    if newSelection.contains(hit.id) { newSelection.remove(hit.id) } else { newSelection.insert(hit.id) }
                } else if !newSelection.contains(hit.id) {
                    newSelection = [hit.id]
                }
                let movable = annotations.filter { newSelection.contains($0.id) && !$0.isLocked }
                if newSelection.contains(hit.id), !movable.isEmpty {
                    let copies = modifiers.contains(.option) ? movable.map { _ in makeID() } : nil
                    gesture = .move(start: point, originals: movable, copyIDs: copies, started: false)
                } else {
                    gesture = .idle
                }
                return ToolResult(selection: newSelection)
            }
            let base = modifiers.contains(.shift) ? selection : []
            gesture = .marquee(start: point, base: base)
            return ToolResult(selection: base)

        case .drag(let point, let modifiers):
            switch gesture {
            case .marquee(let start, let base):
                let rect = CGRect.bounding([start, point])
                return ToolResult(selection: base.union(HitTesting.ids(intersecting: rect, in: annotations)), marquee: rect)
            case .move(let start, let originals, let copyIDs, let started):
                let delta = constrainedDelta(from: start, to: point, modifiers)
                guard started || hypot(point.x - start.x, point.y - start.y) >= dragThreshold else { return ToolResult() }
                gesture = .move(start: start, originals: originals, copyIDs: copyIDs, started: true)
                return ToolResult(preview: movedPreview(originals, copyIDs: copyIDs, delta: delta, in: annotations))
            case .resize(let handle, let original):
                let resized = AnnotationGeometry.resized(original, handle: handle, to: point, keepAspect: modifiers.contains(.shift))
                return ToolResult(preview: replacing([resized], in: annotations))
            case .rotate(let original):
                let rotated = AnnotationGeometry.rotated(original, pointer: point, snap: modifiers.contains(.shift))
                return ToolResult(preview: replacing([rotated], in: annotations))
            case .idle, .create:
                return ToolResult()
            }

        case .up(let point, let modifiers):
            defer { gesture = .idle }
            switch gesture {
            case .marquee(let start, let base):
                let rect = CGRect.bounding([start, point])
                return ToolResult(selection: base.union(HitTesting.ids(intersecting: rect, in: annotations)))
            case .move(let start, let originals, let copyIDs, let started):
                guard started else { return ToolResult() }
                let delta = constrainedDelta(from: start, to: point, modifiers)
                let after = originals.map { AnnotationGeometry.moved($0, by: delta) }
                if let copyIDs {
                    let copies = zip(after, copyIDs).map { moved, id in
                        Annotation(id: id, kind: moved.kind, style: moved.style, rotation: moved.rotation, isLocked: false)
                    }
                    return ToolResult(command: AddAnnotations(copies, name: "Duplica"), selection: Set(copyIDs))
                }
                return ToolResult(command: UpdateAnnotations(name: "Sposta", before: originals, after: after))
            case .resize(let handle, let original):
                let after = AnnotationGeometry.resized(original, handle: handle, to: point, keepAspect: modifiers.contains(.shift))
                guard after != original else { return ToolResult() }
                return ToolResult(command: UpdateAnnotations(name: "Ridimensiona", before: [original], after: [after]))
            case .rotate(let original):
                let after = AnnotationGeometry.rotated(original, pointer: point, snap: modifiers.contains(.shift))
                guard after != original else { return ToolResult() }
                return ToolResult(command: UpdateAnnotations(name: "Ruota", before: [original], after: [after]))
            case .idle, .create:
                return ToolResult()
            }

        case .key:
            return ToolResult()
        }
    }

    // MARK: Creazione (Task 6)

    private func handleCreate(_ event: ToolEvent, document: PinxelDocument) -> ToolResult {
        ToolResult()
    }

    // MARK: Aiuti

    private func constrainedDelta(from start: CGPoint, to point: CGPoint, _ modifiers: ToolModifiers) -> CGSize {
        var delta = CGSize(width: point.x - start.x, height: point.y - start.y)
        if modifiers.contains(.shift) {
            if abs(delta.width) >= abs(delta.height) { delta.height = 0 } else { delta.width = 0 }
        }
        return delta
    }

    private func movedPreview(_ originals: [Annotation], copyIDs: [UUID]?, delta: CGSize, in annotations: [Annotation]) -> [Annotation] {
        let moved = originals.map { AnnotationGeometry.moved($0, by: delta) }
        guard let copyIDs else { return replacing(moved, in: annotations) }
        return annotations + zip(moved, copyIDs).map { moved, id in
            Annotation(id: id, kind: moved.kind, style: moved.style, rotation: moved.rotation, isLocked: false)
        }
    }

    private func replacing(_ changed: [Annotation], in annotations: [Annotation]) -> [Annotation] {
        let byID = Dictionary(changed.map { ($0.id, $0) }, uniquingKeysWith: { first, _ in first })
        return annotations.map { byID[$0.id] ?? $0 }
    }
}
```

```swift
    // MARK: Creazione

    private func handleCreate(_ event: ToolEvent, document: PinxelDocument) -> ToolResult {
        let annotations = document.annotations
        switch event {
        case .down(let point, let modifiers, _):
            let id = makeID()
            gesture = .create(start: point, id: id, points: [point])
            // Lo step compare subito sotto il puntatore.
            guard let annotation = makeAnnotation(id: id, start: point, end: point, points: [point], modifiers: modifiers) else {
                return ToolResult()
            }
            return ToolResult(preview: annotations + [annotation])

        case .drag(let point, let modifiers):
            guard case .create(let start, let id, var points) = gesture else { return ToolResult() }
            if let last = points.last, last.distance(to: point) >= 1 { points.append(point) }
            gesture = .create(start: start, id: id, points: points)
            guard let annotation = makeAnnotation(id: id, start: start, end: point, points: points, modifiers: modifiers) else {
                return ToolResult()
            }
            return ToolResult(preview: annotations + [annotation])

        case .up(let point, let modifiers):
            guard case .create(let start, let id, var points) = gesture else { return ToolResult() }
            gesture = .idle
            if let last = points.last, last.distance(to: point) >= 1 { points.append(point) }
            guard let annotation = makeAnnotation(id: id, start: start, end: point, points: points, modifiers: modifiers) else {
                return ToolResult()
            }
            return ToolResult(command: AddAnnotations([annotation], name: "Aggiungi \(tool.title.lowercased())"), selection: [id])

        case .key:
            return ToolResult()
        }
    }

    private func makeAnnotation(id: UUID, start: CGPoint, end: CGPoint, points: [CGPoint], modifiers: ToolModifiers) -> Annotation? {
        let style = styles.style(for: tool)
        switch tool {
        case .arrow, .line:
            let target = modifiers.contains(.shift) ? AnnotationGeometry.constrained45(from: start, to: end) : end
            guard start.distance(to: target) >= dragThreshold else { return nil }
            let line = LineGeometry(start: start, end: target)
            let kind: Annotation.Kind = tool == .arrow
                ? .arrow(ArrowData(line: line, heads: styles.arrowHeads))
                : .line(LineData(line: line))
            return Annotation(id: id, kind: kind, style: style)
        case .shape, .blur:
            let corner = modifiers.contains(.shift) ? AnnotationGeometry.squared(from: start, to: end) : end
            let rect = CGRect.bounding([start, corner])
            guard rect.width >= dragThreshold, rect.height >= dragThreshold else { return nil }
            if tool == .shape {
                return Annotation(id: id, kind: .shape(ShapeData(rect: rect, shape: styles.shapeType)), style: style)
            }
            let kind: Annotation.Kind = styles.effectMode == .blur
                ? .blur(BlurData(rect: rect, radius: styles.effectAmount))
                : .pixelate(PixelateData(rect: rect, blockSize: styles.effectAmount))
            return Annotation(id: id, kind: kind, style: style)
        case .pen, .highlight:
            guard points.count >= 2 else { return nil }
            let path = PathGeometry(points: points)
            let kind: Annotation.Kind = tool == .pen ? .pen(PenData(path: path)) : .highlight(HighlightData(path: path))
            return Annotation(id: id, kind: kind, style: style)
        case .step:
            let label = StepLabel(sequence: styles.stepSequence)
            return Annotation(id: id, kind: .step(StepData(center: end, diameter: styles.stepDiameter, label: label)), style: style)
        case .select:
            return nil
        }
    }
```

```swift
import CoreGraphics
import DocumentModel
import Foundation

public enum AnnotationEditing {
    /// Comando che applica `change` alle annotazioni indicate e non bloccate; `nil` se nulla cambia.
    public static func update(_ ids: Set<UUID>, in document: PinxelDocument, name: String, _ change: (inout Annotation) -> Void) -> UpdateAnnotations? {
        var before: [Annotation] = []
        var after: [Annotation] = []
        for annotation in document.annotations where ids.contains(annotation.id) && !annotation.isLocked {
            var changed = annotation
            change(&changed)
            if changed != annotation {
                before.append(annotation)
                after.append(changed)
            }
        }
        return before.isEmpty ? nil : UpdateAnnotations(name: name, before: before, after: after)
    }

    public static func setLocked(_ locked: Bool, ids: Set<UUID>, in document: PinxelDocument) -> UpdateAnnotations? {
        let before = document.annotations.filter { ids.contains($0.id) && $0.isLocked != locked }
        guard !before.isEmpty else { return nil }
        let after = before.map { annotation -> Annotation in
            var copy = annotation
            copy.isLocked = locked
            return copy
        }
        return UpdateAnnotations(name: locked ? "Blocca" : "Sblocca", before: before, after: after)
    }

    /// Copie spostate di `offset`, con ID nuovi e sbloccate.
    public static func duplicates(of annotations: [Annotation], offset: CGSize, makeID: () -> UUID = { UUID() }) -> [Annotation] {
        annotations.map { annotation in
            let moved = AnnotationGeometry.moved(annotation, by: offset)
            return Annotation(id: makeID(), kind: moved.kind, style: moved.style, rotation: moved.rotation, isLocked: false)
        }
    }
}

        }

            guard case .shape(let data) = kind else { return nil }
            return data.shape
        }

            guard case .shape(var data) = kind, let newValue else { return }
            data.shape = newValue

        get {
            guard case .step(let data) = kind else { return nil }
            return data.label.sequence
        }
        set {
            guard case .step(var data) = kind, let newValue else { return }
            data.label.sequence = newValue
            kind = .step(data)
        }
    }

    /// Raggio della sfocatura o lato dei blocchi della pixelatura.
    public var effectAmount: Double? {
        get {
            switch kind {
            case .blur(let data): data.radius
            case .pixelate(let data): data.blockSize
            default: nil
            }
        }
        set {
            guard let newValue else { return }
            switch kind {
            case .blur(var data):
                data.radius = newValue
                kind = .blur(data)
            case .pixelate(var data):
                data.blockSize = newValue
                kind = .pixelate(data)
            default:
                break
            }
        }
    }

    public var effectMode: EffectMode? {
        switch kind {
        case .blur: .blur
        case .pixelate: .pixelate
        default: nil
        }
    }

    mutating func convertEffect(to mode: EffectMode) {
        switch (kind, mode) {
        case (.blur(let data), .pixelate): kind = .pixelate(PixelateData(rect: data.rect, blockSize: data.radius))
        case (.pixelate(let data), .blur): kind = .blur(BlurData(rect: data.rect, radius: data.blockSize))
        default: break
        }
    }
```

```swift
/// Tipo di oggetto a cui si riferisce il pannello proprietà.
public enum InspectedKind: Equatable, Sendable {
    case arrow, line, shape, pen, highlight, step, effect, none

    init(_ kind: Annotation.Kind) {
        switch kind {
        case .arrow: self = .arrow
        case .line: self = .line
        case .shape: self = .shape
        case .pen: self = .pen
        case .highlight: self = .highlight
        case .step: self = .step
        case .blur, .pixelate: self = .effect
        default: self = .none
        }
    }

    init(_ tool: EditorTool) {
        switch tool {
        case .select: self = .none
        case .arrow: self = .arrow
        case .line: self = .line
        case .shape: self = .shape
        case .pen: self = .pen
        case .highlight: self = .highlight
        case .step: self = .step
        case .blur: self = .effect
        }
    }

    public var showsStroke: Bool { ![.step, .effect, .none].contains(self) }
    public var showsFill: Bool { self == .shape || self == .step }
    public var showsLineWidth: Bool { showsStroke }
    public var showsDash: Bool { [.arrow, .line, .shape].contains(self) }
    public var showsOpacity: Bool { self != .effect && self != .none }
    public var showsShadow: Bool { ![.effect, .highlight, .none].contains(self) }
}

/// Stato della finestra dell'editor oltre al documento: strumento attivo, stili degli strumenti, pannello.
@MainActor
@Observable
public final class EditorModel {
    public let session: EditorSession
    public var tool: EditorTool = .select
    public var toolStyles = ToolStyles()
    public var isInspectorPresented = true

    public init(session: EditorSession) {
        self.session = session
    }

    public var inspectedAnnotation: Annotation? { session.selectedAnnotations.first }

    public var inspectedKind: InspectedKind {
        if let annotation = inspectedAnnotation { return InspectedKind(annotation.kind) }
        return InspectedKind(tool)
    }

    /// Stile della prima annotazione selezionata, altrimenti quello dello strumento attivo.
    public var inspectedStyle: Style {
        inspectedAnnotation?.style ?? toolStyles.style(for: tool)
    }

    public func setStyle<Value: Equatable>(_ keyPath: WritableKeyPath<Style, Value>, _ value: Value, coalescing: Bool = false) {
        let tool = self.tool
        update(name: "Stile", coalescing: coalescing, selection: { $0.style[keyPath: keyPath] = value }, tool: { styles in
            styles.styles[tool, default: ToolStyles.defaultStyle(for: tool)][keyPath: keyPath] = value
        })
    }

    public func previewStyle<Value: Equatable>(_ keyPath: WritableKeyPath<Style, Value>, _ value: Value) {
        let tool = self.tool
        previewUpdate(selection: { $0.style[keyPath: keyPath] = value }, tool: { styles in
            styles.styles[tool, default: ToolStyles.defaultStyle(for: tool)][keyPath: keyPath] = value
        })
    }

    /// Con una selezione modifica le annotazioni selezionate (un comando); altrimenti gli stili dello strumento.
    public func update(name: String, coalescing: Bool = false,
                       selection change: (inout Annotation) -> Void,
                       tool toolChange: (inout ToolStyles) -> Void) {
        if session.selection.isEmpty {
            toolChange(&toolStyles)
        } else if let command = AnnotationEditing.update(session.selection, in: session.document, name: name, change) {
            session.perform(command, coalescingKey: coalescing ? name : nil)
        }
    }

    /// Anteprima non registrata di una modifica in corso (cursore trascinato).
    public func previewUpdate(selection change: (inout Annotation) -> Void, tool toolChange: (inout ToolStyles) -> Void) {
        if session.selection.isEmpty {
            toolChange(&toolStyles)
            return
        }
        guard !session.isReadOnly else { return }
        let selection = session.selection
        session.preview = session.document.annotations.map { annotation in
            guard selection.contains(annotation.id), !annotation.isLocked else { return annotation }
            var copy = annotation
            change(&copy)
            return copy
        }
    }

    public func setEffectMode(_ mode: EffectMode) {
        update(name: "Effetto", selection: { $0.convertEffect(to: mode) }, tool: { $0.effectMode = mode })
    }

    /// Attiva lo strumento del tasto premuto; `false` se il tasto non è di nessuno strumento.
    @discardableResult
    public func selectTool(forKey characters: String) -> Bool {
        guard characters.count == 1, let first = characters.first, let tool = EditorTool.forShortcut(first) else { return false }
        self.tool = tool
        return true
    }
}
```

```swift
import CoreGraphics
import DocumentModel
import Foundation

/// Contenuto degli appunti per copiare annotazioni tra documenti (tipo privato, spec §6.3).
public enum AnnotationClipboard {
    public static let typeIdentifier = "com.degiorgi.pinxel.annotations"
    public static let pasteOffset = CGSize(width: 10, height: 10)

    public static func encode(_ annotations: [Annotation]) throws -> Data {
        try JSONEncoder().encode(annotations)
    }

    public static func decode(_ data: Data) throws -> [Annotation] {
        try JSONDecoder().decode([Annotation].self, from: data)
    }

    /// Copie da incollare: ID nuovi, spostate di `pasteOffset`, sbloccate. Le immagini incollate restano
    /// fuori perché i loro file non viaggiano negli appunti.
    public static func prepareForPaste(_ annotations: [Annotation], makeID: () -> UUID = { UUID() }) -> [Annotation] {
        annotations.compactMap { annotation in
            if case .image = annotation.kind { return nil }
            let moved = AnnotationGeometry.moved(annotation, by: pasteOffset)
            return Annotation(id: makeID(), kind: moved.kind, style: moved.style, rotation: moved.rotation, isLocked: false)
        }
    }

    /// Riquadro della tela (pixel, padding incluso) da ritagliare per il PNG che accompagna le annotazioni.
    public static func cropRect(for annotations: [Annotation], padding: Double, canvasSize: CGSize, margin: Double = 8) -> CGRect? {
        let union = annotations.map(HitTesting.worldBounds).filter { !$0.isNull }.reduce(CGRect.null) { $0.union($1) }
        guard !union.isNull else { return nil }
        let rect = union.offsetBy(dx: padding, dy: padding)
            .insetBy(dx: -margin, dy: -margin)
            .integral
            .intersection(CGRect(origin: .zero, size: canvasSize))
        return rect.isNull || rect.isEmpty ? nil : rect
    }
}
```

```swift
import AppKit
import DocumentModel
import Observation
import Rendering

/// Azioni dei menu dell'editor, inviate alla catena dei responder.
@MainActor
@objc public protocol EditorActions {
    func zoomIn(_ sender: Any?)
    func zoomOut(_ sender: Any?)
    func zoomToFit(_ sender: Any?)
    func zoomToActualSize(_ sender: Any?)
    func bringToFront(_ sender: Any?)
    func bringForward(_ sender: Any?)
    func sendBackward(_ sender: Any?)
    func sendToBack(_ sender: Any?)
    func duplicateSelection(_ sender: Any?)
    func lockSelection(_ sender: Any?)
    func unlockSelection(_ sender: Any?)
}

/// Tela dell'editor: disegna il documento con `DocumentRenderer` e trasforma mouse e tastiera in eventi
/// per il `ToolController`.
@MainActor
public final class CanvasView: NSView, EditorActions {
    public let model: EditorModel
    let controller = ToolController()
    private(set) var viewport: Viewport
    /// Appunti di Copia/Incolla; i test ne usano uno privato.
    var pasteboard: NSPasteboard = .general

    private let renderer = DocumentRenderer()
    private var marquee: CGRect?
    /// Finché l'utente non cambia zoom o posizione, la tela segue le dimensioni della finestra.
    private var followsWindow = true
    private var spaceHeld = false
    private var panPoint: CGPoint?
    private var renderFailed = false

    static let annotationsType = NSPasteboard.PasteboardType(AnnotationClipboard.typeIdentifier)

    private var session: EditorSession { model.session }

    public init(model: EditorModel) {
        self.model = model
        viewport = Viewport(documentScale: model.session.document.scale)
        super.init(frame: .zero)
        setAccessibilityElement(true)
        setAccessibilityRole(.image)
        setAccessibilityLabel("Tela")
        setAccessibilityIdentifier("pinxel.editor.canvas")
        updateAccessibilityValue()
        observeModel()
    }

    @available(*, unavailable)
    required init?(coder: NSCoder) { fatalError("init(coder:) is not supported") }

    public override var isFlipped: Bool { true }
    public override var acceptsFirstResponder: Bool { true }
    public override func acceptsFirstMouse(for event: NSEvent?) -> Bool { true }

    public override func viewDidMoveToWindow() {
        super.viewDidMoveToWindow()
        window?.makeFirstResponder(self)
    }

    // MARK: Coordinate

    var canvasSize: CGSize { renderer.canvasSize(for: session.document) }
    private var padding: Double { session.document.canvasStyle.padding }
    private var viewCenter: CGPoint { CGPoint(x: bounds.midX, y: bounds.midY) }

    /// Punto del documento (spazio delle annotazioni) sotto un punto della vista.
    func documentPoint(fromView point: CGPoint) -> CGPoint {
        let canvas = viewport.canvasPoint(fromView: point)
        return CGPoint(x: canvas.x - padding, y: canvas.y - padding)
    }

    func viewPoint(fromDocument point: CGPoint) -> CGPoint {
        viewport.viewPoint(fromCanvas: CGPoint(x: point.x + padding, y: point.y + padding))
    }

    public override func layout() {
        super.layout()
        if followsWindow, bounds.width > 0, bounds.height > 0 {
            viewport.fit(canvasSize: canvasSize, in: bounds.size)
        }
    }

    private func observeModel() {
        withObservationTracking {
            _ = session.document
            _ = session.selection
            _ = session.preview
            _ = model.tool
        } onChange: { [weak self] in
            Task { @MainActor [weak self] in
                guard let self else { return }
                self.needsDisplay = true
                self.updateAccessibilityValue()
                self.window?.invalidateCursorRects(for: self)
                self.observeModel()
            }
        }
    }

    private func updateAccessibilityValue() {
        setAccessibilityValue("Annotazioni: \(session.document.annotations.count), selezionate: \(session.selection.count)")
    }

    // MARK: Disegno

    public override func draw(_ dirtyRect: NSRect) {
        guard let ctx = NSGraphicsContext.current?.cgContext else { return }
        syncController()
        NSColor.underPageBackgroundColor.setFill()
        bounds.fill()

        let size = canvasSize
        let canvasRect = viewport.viewRect(fromCanvas: CGRect(origin: .zero, size: size))
        drawCheckerboard(in: canvasRect, context: ctx)

        var document = session.document
        document.annotations = session.displayedAnnotations
        ctx.saveGState()
        ctx.clip(to: canvasRect)
        ctx.interpolationQuality = viewport.zoom >= 2 ? .none : .high
        ctx.translateBy(x: viewport.origin.x, y: viewport.origin.y)
        ctx.scaleBy(x: viewport.pointsPerPixel, y: viewport.pointsPerPixel)
        // Il renderer capovolge per un contesto con origine in basso; questa vista è già capovolta.
        ctx.translateBy(x: 0, y: size.height)
        ctx.scaleBy(x: 1, y: -1)
        do {
            try renderer.render(document, assets: session.assets, in: ctx)
            renderFailed = false
        } catch {
            renderFailed = true
        }
        ctx.restoreGState()

        if renderFailed { drawMessage("Impossibile mostrare l'immagine del documento.") }
        drawSelection(in: ctx)
        if let marquee { drawMarquee(marquee, in: ctx) }
    }

    private func drawCheckerboard(in rect: CGRect, context ctx: CGContext) {
        let visible = rect.intersection(bounds)
        guard !visible.isNull, !visible.isEmpty else { return }
        let square: CGFloat = 8
        ctx.saveGState()
        ctx.clip(to: visible)
        ctx.setFillColor(NSColor.white.cgColor)
        ctx.fill(visible)
        ctx.setFillColor(NSColor(white: 0.85, alpha: 1).cgColor)
        let firstRow = Int(((visible.minY - rect.minY) / square).rounded(.down))
        let firstColumn = Int(((visible.minX - rect.minX) / square).rounded(.down))
        var row = firstRow
        while rect.minY + CGFloat(row) * square < visible.maxY {
            var column = firstColumn
            while rect.minX + CGFloat(column) * square < visible.maxX {
                if (row + column) % 2 != 0 {
                    ctx.fill(CGRect(x: rect.minX + CGFloat(column) * square, y: rect.minY + CGFloat(row) * square, width: square, height: square))
                }
                column += 1
            }
            row += 1
        }
        ctx.restoreGState()
    }

    private func drawSelection(in ctx: CGContext) {
        let selected = session.displayedAnnotations.filter { session.selection.contains($0.id) }
        guard !selected.isEmpty else { return }
        ctx.saveGState()
        ctx.setLineWidth(1)
        ctx.setStrokeColor(NSColor.controlAccentColor.cgColor)
        for annotation in selected {
            let bounds = annotation.bounds
            guard !bounds.isNull else { continue }
            switch annotation.kind {
            case .arrow, .line: continue // bastano le maniglie agli estremi
            default: break
            }
            let corners = HitTesting.corners(of: bounds).map {
                viewPoint(fromDocument: $0.rotated(around: bounds.center, by: annotation.rotation))
            }
            ctx.setLineDash(phase: 0, lengths: annotation.isLocked ? [4, 3] : [])
            ctx.addLines(between: corners)
            ctx.closePath()
            ctx.strokePath()
        }
        ctx.setLineDash(phase: 0, lengths: [])
        if selected.count == 1, let annotation = selected.first {
            let handles = HitTesting.handles(for: annotation, rotationOffset: controller.rotationHandleOffset)
            if let rotation = handles.first(where: { $0.handle == .rotation }), let top = handles.first(where: { $0.handle == .top }) {
                ctx.move(to: viewPoint(fromDocument: top.point))
                ctx.addLine(to: viewPoint(fromDocument: rotation.point))
                ctx.strokePath()
            }
            ctx.setFillColor(NSColor.white.cgColor)
            for (handle, point) in handles {
                let center = viewPoint(fromDocument: point)
                let rect = CGRect(x: center.x - 4, y: center.y - 4, width: 8, height: 8)
                if handle == .rotation {
                    ctx.fillEllipse(in: rect)
                    ctx.strokeEllipse(in: rect)
                } else {
                    ctx.fill(rect)
                    ctx.stroke(rect)
                }
            }
        }
        ctx.restoreGState()
    }

    private func drawMarquee(_ rect: CGRect, in ctx: CGContext) {
        let area = CGRect.bounding([viewPoint(fromDocument: rect.origin), viewPoint(fromDocument: CGPoint(x: rect.maxX, y: rect.maxY))])
        ctx.saveGState()
        ctx.setFillColor(NSColor.controlAccentColor.withAlphaComponent(0.12).cgColor)
        ctx.fill(area)
        ctx.setStrokeColor(NSColor.controlAccentColor.cgColor)
        ctx.setLineWidth(1)
        ctx.stroke(area.insetBy(dx: 0.5, dy: 0.5))
        ctx.restoreGState()
    }

    private func drawMessage(_ text: String) {
        let attributes: [NSAttributedString.Key: Any] = [
            .font: NSFont.systemFont(ofSize: 13),
            .foregroundColor: NSColor.secondaryLabelColor,
        ]
        let size = (text as NSString).size(withAttributes: attributes)
        (text as NSString).draw(at: CGPoint(x: bounds.midX - size.width / 2, y: bounds.midY - size.height / 2), withAttributes: attributes)
    }

    // MARK: Eventi

    private func syncController() {
        if controller.tool != model.tool { controller.tool = model.tool }
        controller.styles = model.toolStyles
        let pointsPerPixel = viewport.pointsPerPixel
        controller.hitTolerance = 4 / pointsPerPixel
        controller.rotationHandleOffset = 24 / pointsPerPixel
        controller.dragThreshold = 3 / pointsPerPixel
    }

    private func modifiers(of event: NSEvent) -> ToolModifiers {
        var result: ToolModifiers = []
        if event.modifierFlags.contains(.shift) { result.insert(.shift) }
        if event.modifierFlags.contains(.option) { result.insert(.option) }
        if event.modifierFlags.contains(.command) { result.insert(.command) }
        return result
    }

    func send(_ event: ToolEvent) {
        syncController()
        apply(controller.handle(event, document: session.document, selection: session.selection))
    }

    private func apply(_ result: ToolResult) {
        marquee = result.marquee
        defer { needsDisplay = true }
        guard !session.isReadOnly else {
            // Sola lettura: si può selezionare, non modificare.
            if let selection = result.selection { session.selection = selection }
            session.preview = nil
            return
        }
        session.preview = result.preview
        // Prima il comando: un oggetto nuovo deve esistere per poter essere selezionato.
        if let command = result.command { session.perform(command) }
        if let selection = result.selection { session.selection = selection }
        if let delta = result.nudge { session.nudge(by: delta) }
    }

    public override func mouseDown(with event: NSEvent) {
        window?.makeFirstResponder(self)
        let point = convert(event.locationInWindow, from: nil)
        if spaceHeld {
            panPoint = point
            NSCursor.closedHand.set()
            return
        }
        send(.down(documentPoint(fromView: point), modifiers(of: event), clickCount: event.clickCount))
    }

    public override func mouseDragged(with event: NSEvent) {
        let point = convert(event.locationInWindow, from: nil)
        if let last = panPoint {
            pan(by: CGSize(width: point.x - last.x, height: point.y - last.y))
            panPoint = point
            return
        }
        send(.drag(documentPoint(fromView: point), modifiers(of: event)))
    }

    public override func mouseUp(with event: NSEvent) {
        let point = convert(event.locationInWindow, from: nil)
        if panPoint != nil {
            panPoint = nil
            (spaceHeld ? NSCursor.openHand : NSCursor.arrow).set()
            return
        }
        send(.up(documentPoint(fromView: point), modifiers(of: event)))
    }

    public override func keyDown(with event: NSEvent) {
        let modifiers = modifiers(of: event)
        switch event.keyCode {
        case 51, 117: send(.key(.delete, modifiers))
        case 53: send(.key(.escape, modifiers))
        case 123: send(.key(.left, modifiers))
        case 124: send(.key(.right, modifiers))
        case 125: send(.key(.down, modifiers))
        case 126: send(.key(.up, modifiers))
        case 49:
            if !spaceHeld {
                spaceHeld = true
                NSCursor.openHand.set()
            }
        default:
            let flags = event.modifierFlags.intersection([.command, .control, .option])
            if flags.isEmpty, let characters = event.charactersIgnoringModifiers, model.selectTool(forKey: characters) { return }
            super.keyDown(with: event)
        }
    }

    public override func keyUp(with event: NSEvent) {
        guard event.keyCode == 49 else {
            super.keyUp(with: event)
            return
        }
        spaceHeld = false
        window?.invalidateCursorRects(for: self)
    }

    public override func resetCursorRects() {
        addCursorRect(bounds, cursor: model.tool == .select ? .arrow : .crosshair)
    }

    public override func scrollWheel(with event: NSEvent) {
        let factor: CGFloat = event.hasPreciseScrollingDeltas ? 1 : 10
        if event.modifierFlags.contains(.command) {
            let anchor = convert(event.locationInWindow, from: nil)
            setZoom(viewport.zoom * (1 + event.scrollingDeltaY * factor / 200), anchor: anchor)
        } else {
            pan(by: CGSize(width: event.scrollingDeltaX * factor, height: event.scrollingDeltaY * factor))
        }
    }

    public override func magnify(with event: NSEvent) {
        setZoom(viewport.zoom * (1 + event.magnification), anchor: convert(event.locationInWindow, from: nil))
    }

    private func setZoom(_ zoom: Double, anchor: CGPoint) {
        viewport.setZoom(zoom, anchor: anchor)
        followsWindow = false
        needsDisplay = true
    }

    private func pan(by delta: CGSize) {
        viewport.pan(by: delta)
        followsWindow = false
        needsDisplay = true
    }

    // MARK: Azioni dei menu

    @objc public func zoomIn(_ sender: Any?) {
        setZoom(Viewport.zoomLevels.first { $0 > viewport.zoom + 1e-9 } ?? Viewport.zoomRange.upperBound, anchor: viewCenter)
    }

    @objc public func zoomOut(_ sender: Any?) {
        setZoom(Viewport.zoomLevels.last { $0 < viewport.zoom - 1e-9 } ?? Viewport.zoomRange.lowerBound, anchor: viewCenter)
    }

    @objc public func zoomToFit(_ sender: Any?) {
        followsWindow = true
        viewport.fit(canvasSize: canvasSize, in: bounds.size)
        needsDisplay = true
    }

    @objc public func zoomToActualSize(_ sender: Any?) {
        followsWindow = false
        viewport.actualSize(canvasSize: canvasSize, in: bounds.size)
        needsDisplay = true
    }

    @objc public func bringToFront(_ sender: Any?) { arrange(ReorderAnnotations.bringToFront) }
    @objc public func bringForward(_ sender: Any?) { arrange(ReorderAnnotations.bringForward) }
    @objc public func sendBackward(_ sender: Any?) { arrange(ReorderAnnotations.sendBackward) }
    @objc public func sendToBack(_ sender: Any?) { arrange(ReorderAnnotations.sendToBack) }

    @objc public func duplicateSelection(_ sender: Any?) {
        let selected = session.selectedAnnotations.filter { !$0.isLocked }
        guard !selected.isEmpty, !session.isReadOnly else { return }
        let copies = AnnotationEditing.duplicates(of: selected, offset: AnnotationClipboard.pasteOffset)
        session.perform(AddAnnotations(copies, name: "Duplica"))
        session.selection = Set(copies.map(\.id))
    }

    @objc public func lockSelection(_ sender: Any?) {
        if let command = AnnotationEditing.setLocked(true, ids: session.selection, in: session.document) { session.perform(command) }
    }

    @objc public func unlockSelection(_ sender: Any?) {
        if let command = AnnotationEditing.setLocked(false, ids: session.selection, in: session.document) { session.perform(command) }
    }

    private func arrange(_ make: (Set<UUID>, PinxelDocument) -> ReorderAnnotations) {
        let ids = Set(session.selectedAnnotations.filter { !$0.isLocked }.map(\.id))
        guard !ids.isEmpty else { return }
        let command = make(ids, session.document)
        var changed = session.document
        command.apply(to: &changed)
        guard changed != session.document else { return }
        session.perform(command)
    }

    @objc public func copy(_ sender: Any?) {
        guard let image = try? renderer.renderImage(session.document, assets: session.assets) else {
            NSSound.beep()
            return
        }
        let selected = session.selectedAnnotations
        pasteboard.clearContents()
        guard !selected.isEmpty else {
            writeImage(image)
            return
        }
        if let data = try? AnnotationClipboard.encode(selected) {
            pasteboard.setData(data, forType: Self.annotationsType)
        }
        if let rect = AnnotationClipboard.cropRect(for: selected, padding: padding, canvasSize: canvasSize),
           let crop = image.cropping(to: rect) {
            writeImage(crop)
        }
    }

    @objc public func cut(_ sender: Any?) {
        copy(sender)
        delete(sender)
    }

    @objc public func paste(_ sender: Any?) {
        guard !session.isReadOnly, let data = pasteboard.data(forType: Self.annotationsType),
              let annotations = try? AnnotationClipboard.decode(data) else {
            NSSound.beep()
            return
        }
        let copies = AnnotationClipboard.prepareForPaste(annotations)
        guard !copies.isEmpty else { return }
        session.perform(AddAnnotations(copies, name: "Incolla"))
        session.selection = Set(copies.map(\.id))
    }

    @objc public func delete(_ sender: Any?) {
        send(.key(.delete, []))
    }

    @objc public func selectAll(_ sender: Any?) {
        session.selection = Set(session.document.annotations.map(\.id))
    }

    private func writeImage(_ image: CGImage) {
        let representation = NSBitmapImageRep(cgImage: image)
        if let png = representation.representation(using: .png, properties: [:]) {
            pasteboard.setData(png, forType: .png)
        }
        if let tiff = representation.tiffRepresentation {
            pasteboard.setData(tiff, forType: .tiff)
        }
    }
}
```

Note: `zoomIn(_:)`/`zoomOut(_:)` go through `setZoom` so menu zoom also stops window-following; `Viewport.zoomIn/zoomOut` stay for code that drives the viewport directly.

```swift
import SwiftUI

/// Cursore che durante il trascinamento mostra solo un'anteprima e alla fine registra un solo comando
/// (spec §5.4). Le modifiche da tastiera, senza trascinamento, si registrano subito.
struct CommittingSlider: View {
    let value: Double
    let range: ClosedRange<Double>
    let preview: @MainActor (Double) -> Void
    let commit: @MainActor (Double) -> Void

    @State private var draft: Double?
    @State private var isEditing = false

    var body: some View {
        Slider(
            value: Binding(
                get: { draft ?? value },
                set: { newValue in
                    if isEditing {
                        draft = newValue
                        preview(newValue)
                    } else {
                        commit(newValue)
                    }
                }
            ),
            in: range
        ) { editing in
            isEditing = editing
            if !editing, let final = draft {
                draft = nil
                commit(final)
            }
        }
    }
}
```

```swift
        let imageHeight = Double(document.imageSize.height) / document.scale

            width: min(max(imageWidth + 260 + 80, 800), visible.width * 0.9),
            height: min(max(imageHeight + 80, 520), visible.height * 0.9)
        )
    }
```

```swift
import AppKit
import AppCore
import DocumentModel
import EditorUI
import Persistence
import Rendering

@objc(PinxelFileDocument)
final class PinxelFileDocument: NSDocument {
    // NSDocument legge e scrive sul thread principale (canConcurrentlyReadDocuments e
    // canAsynchronouslyWrite sono false), ma i metodi non sono isolati.
    nonisolated(unsafe) private(set) var contents: PinxelFileContents?
    /// Creato con la finestra: da lì in poi il documento aggiornato è `editorModel.session.document`.
    nonisolated(unsafe) private(set) var editorModel: EditorModel?

    convenience init(contents: PinxelFileContents) {
        self.init()
        self.contents = contents
        fileType = "com.degiorgi.pinxel.document"
    }

    override class var autosavesInPlace: Bool { true }

    override func canAsynchronouslyWrite(to url: URL, ofType typeName: String, for saveOperation: NSDocument.SaveOperationType) -> Bool {
        false
    }

    override func read(from data: Data, ofType typeName: String) throws {
        do {
            contents = try PinxelArchive.read(data)
        } catch {
            throw Self.userError(for: error, data: data)
        }
    }

    override func data(ofType typeName: String) throws -> Data {
        guard var contents else { throw CocoaError(.fileWriteUnknown) }
        if let edited = MainActor.assumeIsolated({ editorModel?.session.document }) {
            contents.document = edited
        }
        guard !contents.isReadOnly else {
            throw NSError(domain: "com.degiorgi.pinxel", code: 1, userInfo: [
                NSLocalizedDescriptionKey: "Questo documento è stato creato da una versione più recente di Pinxel e si può solo leggere.",
            ])
        }
        let assets = try contents.assetProvider()
        let thumbnail = try Thumbnailer.make(contents.document, assets: assets)
        let version = Bundle.main.object(forInfoDictionaryKey: "CFBundleShortVersionString") as? String ?? "0.1.0"
        return try PinxelArchive.write(document: contents.document, images: contents.images, thumbnail: thumbnail, appVersion: version)
    }

    override func makeWindowControllers() {
        MainActor.assumeIsolated {
            guard let contents else { return }
            do {
                let session = EditorSession(
                    document: contents.document,
                    assets: try contents.assetProvider(),
                    undoManager: undoManager ?? UndoManager(),
                    isReadOnly: contents.isReadOnly
                )
                let model = EditorModel(session: session)
                editorModel = model
                addWindowController(EditorWindowController(model: model))
            } catch {
                // Senza immagini il documento non si può mostrare: avvisa e chiudi, niente documenti senza finestra.
                presentError(error)
                perform(#selector(NSDocument.close), with: nil, afterDelay: 0)
            }
        }
    }

    nonisolated private static func userError(for error: Error, data: Data) -> NSError {
        let reason: String
        switch error {
        case PinxelArchiveError.notAPinxelFile: reason = "Il file non è un documento Pinxel."
        case PinxelArchiveError.invalidDocument(let detail): reason = "Il documento è danneggiato (\(detail))."
        case PinxelArchiveError.missingAsset(let name): reason = "Nel documento manca l'immagine \(name)."
        default: reason = "Il file è danneggiato o illeggibile."
        }
```

```swift
import Foundation
import Persistence
import UniformTypeIdentifiers

public enum ExportFileType: String, CaseIterable, Sendable {
    case png, jpeg, heic, pdf

    public var title: String {
        switch self {
        case .png: "PNG"
        case .jpeg: "JPEG"
        case .heic: "HEIC"
        case .pdf: "PDF"
        }
    }

    public var fileExtension: String {
        switch self {
        case .png: "png"
        case .jpeg: "jpg"
        case .heic: "heic"
        case .pdf: "pdf"
        }
    }

    public var contentType: UTType {
        switch self {
        case .png: .png
        case .jpeg: .jpeg
        case .heic: .heic
        case .pdf: .pdf
        }
    }

    public var hasQuality: Bool { self == .jpeg || self == .heic }
}

/// Scelte del pannello Esporta… tradotte nei formati di `Exporter` (spec §9).
public struct ExportChoice: Equatable, Sendable {
    private static let replaceableExtensions: Set<String> = ["pinxel", "png", "jpg", "jpeg", "heic", "pdf"]

    public var fileType: ExportFileType = .png
    /// 0...100.
    public var quality: Double = 90
    public var scale: ExportScale

    /// Per una cattura Retina il default è 2x (pixel nativi), altrimenti 1x.
    public init(documentScale: Double) {
        scale = documentScale >= 2 ? .twoX : .oneX
    }

    public var format: ExportFormat {
        let normalized = min(max(quality, 0), 100) / 100
        switch fileType {
        case .png: return .png
        case .jpeg: return .jpeg(quality: normalized)
        case .heic: return .heic(quality: normalized)
        case .pdf: return .pdf
        }
    }

    /// Nome con l'estensione del formato scelto; sostituisce solo estensioni note.
    public func fileName(from baseName: String) -> String {
        let name = baseName as NSString
        let base = Self.replaceableExtensions.contains(name.pathExtension.lowercased()) ? name.deletingPathExtension : baseName
        return (base.isEmpty ? "Pinxel" : base) + "." + fileType.fileExtension
    }
}
```

```swift
/// Esporta… (spec §9): pannello di salvataggio con formato, qualità e scala; passa da `Exporter`.
@MainActor
enum ExportPanel {
    static func run(document: PinxelDocument, assets: any AssetProvider, suggestedName: String, window: NSWindow) async {
        let options = ExportOptions(choice: ExportChoice(documentScale: document.scale))
        let panel = NSSavePanel()
        panel.title = "Esporta"
        panel.prompt = "Esporta"
        panel.canCreateDirectories = true
        panel.isExtensionHidden = false
        panel.allowedContentTypes = [options.choice.fileType.contentType]
        panel.nameFieldStringValue = options.choice.fileName(from: suggestedName)
        panel.accessoryView = NSHostingView(rootView: ExportOptionsView(options: options) { fileType in
            panel.allowedContentTypes = [fileType.contentType]
            panel.nameFieldStringValue = options.choice.fileName(from: panel.nameFieldStringValue)
        })

        guard await panel.beginSheetModal(for: window) == .OK, let url = panel.url else { return }
        do {
            let data = try Exporter.export(document, assets: assets, format: options.choice.format, scale: options.choice.scale)
            try data.write(to: url, options: .atomic)
        } catch {
            window.presentError(error)
        }
    }
}
```
